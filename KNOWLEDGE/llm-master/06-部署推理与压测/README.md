## 本章高频面试题速查

- **Q1: 为什么大模型推理的 Prefill 阶段和 Decode 阶段瓶颈不同？**

  - *回答要点*：Prefill 阶段一次性并行计算整个长 Prompt，是矩阵乘大矩阵（GEMM），计算密集，受 GPU 算力 (TFLOPS) 限制；Decode 阶段每步只生成一个词，是小向量乘巨幅历史 KV 缓存（GEMV），访存密集，受 GPU 显存带宽 (GB/s) 限制。

- **Q2: 为什么各阶段的 P95 耗时不能简单相加？**

  - *回答要点*：极值发生的独立性原理。遭遇最长排队的请求，其 Prompt 可能极短；遭遇最长 Prefill 的请求可能恰好在空闲期进入无需排队。相加会导致结果虚高 30%~50%，必须对每个请求的完整端到端耗时序列统一切分位数。

- **Q3: 为什么大模型权重通常优先选对称量化，而激活值更倾向非对称量化？**

  - *回答要点*：大模型权重基本以 0 为中心对称分布，对称量化零点为 0，计算高效；而激活值经 GELU/ReLU 处理后通常是非负偏斜分布，非对称量化引入动态 Zero-point 能充分利用低比特网格。

- **Q4: 什么是 vLLM 的 PagedAttention 核心思想？**

  - *回答要点*：借鉴操作系统虚拟内存分页，将 KV Cache 离散存储在固定大小的物理 Block 中，通过逻辑块表动态按需分配，彻底消除由于预分配导致的内部碎片与外部碎片。
