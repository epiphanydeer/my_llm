## 本章主线与应用岗核心定位

在针对中国境内外企「Applied MLE / LLM 应用算法工程师」的面试中，多模态大模型 (VLM) 与系统级评测是第一核心重中之重。面对拥有多模态学术背景但缺乏高并发工业落地经验的转行候选人，面试官考核的核心红线是：“能否把论文中理想化的跑分，落地为高鲁棒、低延迟、可排障、抗幻觉的工业生产系统”：

- 从零讲清模态桥接与数据流：视觉特征如何通过 ViT 切块 (Patches) 并经由 Multimodal Projector 投影到 LLM 嵌入空间；为什么“维度匹配绝不等于语义对齐”；

- 生产级排障与抗幻觉防御：为什么小目标容易漏检？如何防范多模态 RAG 中“以法索图、倒果为因”的虚假违规幻觉？为什么必须将画面事实与规程时效解耦核验？

- 真实落地证据与消融对比：如何设计事件级防泄漏切分？为什么拒绝使用单一全局准确率？如何使用成对消融实验 (Pairwise Ablation) 给出 Fixed（变好）与 Regressed（变坏）的净收益及 P95 尾延迟代价。

## 本章高频面试题速查

- Q1: VQA 问答正确率能否直接替代目标检测 mAP？

- 回答要点：绝对不能。VQA 只评估文本语义匹配，大模型极易依靠语言先验猜中答案；只有输出空间检测框并通过 IoU 一对一贪心匹配，才能证明模型真正定位了视觉实体。

- Q2: 为什么微调 VLM 时必须将图像 Token 的 Labels 设为 -100？

- 回答要点：图像 Token 极其庞大且由视觉编码器生成，若对其计算交叉熵损失，会导致优化目标被庞大的视觉特征记忆主导，导致真正需要学习的目标答案梯度被严重稀释。

- Q3: 为什么多模态数据集绝对不能按问答条目随机 Train/Test Split？

- 回答要点：监控视频与现场连拍中连续帧极其相似，随机切分会导致模型通过记忆背景与场景“作弊”，引发严重的事件级数据泄漏，造成测试集虚高而线上泛化暴跌。

- Q4: 什么是多模态 RAG 中的“以法索图”幻觉，如何防御？

- 回答要点：模型因为读到了严厉的安全处罚条款，便在看不清细节的模糊画面中主观臆断并脑补出违规事实。防御策略是将“视觉观察提取”与“法规检索”解耦为双路独立执行，通过确定性逻辑判定时效与证据充分性。

## 学习复习与打卡建议

- 第一阶段（视觉与架构地基 Level 1~3）：吃透目标检测 IoU 贪心匹配、ViT Patch 分块对齐与 Processor 输入流水线，能在白板上手撕特征张量维度流转。

- 第二阶段（数据工程与微调鲁棒性 Level 4~6）：掌握事件级防泄漏切分、主干参数冻结与 -100 损失掩码，以及工业级切片评测矩阵，理解拒答对真实召回率的严格影响。

- 第三阶段（高级时序与系统工程 Level 7~9）：掌握视频 BGR/RGB 与 PTS 时钟对齐、多模态 RAG 双路证据解耦，以及以成对消融和 P95 尾延迟为支撑的作品集答辩表达。
