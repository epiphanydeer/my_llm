## 本章主线与应用岗核心定位

在针对中国境内外企「Applied MLE / LLM 应用算法工程师」的面试中，微调技术是衡量候选人是否具备“算法自研掌控力与工业落地常识”的试金石。面试官不会让你去从头预训练一个千亿基座模型，但会极其严苛地考察以下核心能力：

1. **选型决策边界**：什么时候该用 RAG，什么时候必须微调（SFT）？如何量化评估“Prompt 优先 → RAG 跟进 → SFT 固化格式 → RAG+SFT 组合拳”的投入产出比；

2. **数据工程与防泄漏隔离**：多轮对话中 `labels=-100` 为什么只遮 Prompt 而绝不能漏掉 `<|im_end|>`？为什么必须按实体/文档做正交划分防背景作弊？如何用 MinHash 过滤近重复语料与脱敏 PII；

3. **白板手撕 LoRA 底层内核**：从数学原理推导为什么矩阵 B 必须初始化为全 0 矩阵？如何计算参数压缩比？如何在部署阶段通过 `merge_and_unload()` 抹平推理延迟；

4. **训练监控与消融归因**：如何识别 Val Loss 发散与过拟合？如何设计 Zero-shot vs Few-shot vs LoRA 的三阶段成对消融实验，用 Fixed（变好）与 Regressed（变坏）计算净收益。

## 本章高频面试题速查

- **Q1: 为什么 LoRA 中的低秩矩阵 B 必须初始化为全 0 矩阵？**

  - *回答要点*：若 B 也随机初始化，在训练开始瞬间 $\Delta W = BA \neq 0$，相当于向主干直接叠加了高斯噪声，会瞬间摧毁基座模型原有的语言与常识能力；只有 $B=0$，才能保证训练初始状态 $\Delta W = 0$。

- **Q2: 为什么微调中 `labels=-100` 绝对不能遮盖 assistant 的结束符 `<|im_end|>`？**

  - *回答要点*：结束符是模型判断输出完毕并主动停机的唯一信号。如果将其设为 -100，模型将永远学不会预测退出，在线上推理中会持续输出无意义乱码直到触发最大长度截断。

- **Q3: 为什么大模型微调中“1000 条精标注数据”往往优于“10 万条爬虫低质数据”？**

  - *回答要点*：LIMA 证明了表面对齐假设。基座模型在预训练已掌握世界知识，微调只是激活特定格式与口吻。高质量数据以高信噪比对齐；脏数据则会破坏表征分布并引发严重幻觉。

- **Q4: 为什么上线部署 LoRA 模型可以做到零额外推理延迟？**

  - *回答要点*：通过离线调用 `merge_and_unload()` 算子，直接执行矩阵加法 $W_{\text{merged}} = W_0 + \frac{\alpha}{r} BA$，将旁路增量永久固化回主干权重，推理时无需并行计算两条分支。
