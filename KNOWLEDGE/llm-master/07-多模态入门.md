# 第七章：多模态大模型入门

> 本章对你是 🔥 必会，但 [llm-master 总目录](逐篇精读/README.md)目前仍标“持续更新中”，没有对应的系统教程。以下是为你的图像/文档/视频方向补的学习骨架，来源另附原论文与模型官方资料；不要把本页误认为原仓库已覆盖了视觉模型训练。

## 7.1 图像如何进入语言模型【🔥】

**一句话：** 视觉模型先提取图像特征，再通过连接/投影模块变成语言模型能利用的视觉表示；语言模型结合图片和文字问题生成回答。不同 VLM 的结构会有差异。

~~~text
图片 → 图像预处理 → 视觉编码器 → 视觉 token/特征
文字问题 → tokenizer → 文字 token
视觉与文字表示结合 → 语言模型 → 答案
~~~

**例子：** 图片里一个工人没戴安全帽，用户问“隐患是什么？”视觉编码器要捕捉头部区域和帽子缺失，语言模型再把视觉信息与“隐患分类”任务结合。只调整文本 Prompt 不能补回分辨率过低造成的视觉细节丢失。

**费曼自述：** “VLM 相当于给语言模型加一双眼睛，但图片要先变成模型能处理的视觉表示。看不清和不会按问题回答，是两类不同错误。”

**概念闪卡：** Q：视觉编码器的作用？A：从图像提取可供后续模型使用的特征。Q：连接模块解决什么？A：将视觉表示与语言模型输入空间对齐/桥接。Q：所有 VLM 架构都一样吗？A：不一样，这里是常见入门图景。

来源：[LLaVA 原论文](https://arxiv.org/abs/2304.08485)。

## 7.2 CLIP 与图文相似度【⭐】

**一句话：** CLIP 一类模型分别编码图片和文字，让匹配的图文对在向量空间中更接近；适合图文检索或零样本分类思路，但不是直接生成长答案的 VLM。

**例子：** 输入一张戴/没戴安全帽的图像，比较它与“工人佩戴安全帽”“工人未佩戴安全帽”两段文本的相似度。相似度更高可作为候选判断，但阈值、误报和图片域迁移要在测试集验证。

**费曼自述：** “CLIP 把图和文字放到可比较的向量空间，像检索匹配器；要写完整解释通常还需要生成模型。”

**概念闪卡：** Q：CLIP 与 RAG Embedding 的共同点？A：都把输入映射成向量用于相似度；输入模态和训练目标可不同。Q：相似度最高就代表事实正确吗？A：不是，要测任务准确性和边界。

来源：[CLIP 官方介绍](https://openai.com/index/clip/)。

## 7.3 VQA、检测、文档与视频不是同一个任务【🔥】

**一句话：** 任务先决定输出与评价方法：VQA 给答案，检测给类别与位置，文档理解要读版面/表格，视频还要处理时间顺序。

| 任务 | 最小输入输出 | 关键错误 |
|---|---|---|
VQA | 图片＋问题 → 简短答案 | 看错区域、语言先验代替视觉证据 |
目标检测 | 图片 → 类别＋边框 | 漏检、小目标、框不准 |
文档理解 | 扫描页＋问题 → 字段/证据位置 | OCR 错、表格行列错、跨页漏读 |
视频理解 | 多帧/片段＋问题 → 时间相关答案 | 采样漏关键帧、时序颠倒 |

**例子：** 用户问“有没有没戴安全帽的人？”只需图像级 yes/no，VQA 可以做；若还要在网页标出那个人的位置，就需要框坐标或分割等定位输出。把“回答正确”与“定位正确”混成一个指标，会掩盖项目问题。

**费曼自述：** “先说清模型要交付什么，再选择数据、模型和指标。会看图不等于会定位，也不等于会读长视频。”

**概念闪卡：** Q：VQA 的答案准确率能评估框定位吗？A：不能。Q：视频为什么不能简单看作一张长图片？A：事件顺序和关键帧采样会影响答案。

来源：本节为面向你项目的补充框架；具体模型以所选模型官方文档为准。

## 7.4 多模态实验与错误分析【🔥】

**一句话：** 按数据、视觉感知、任务理解、生成和检索引用分层记录错误，用同一独立集比较改动。

**例子：** 一张昏暗图像被判为“无隐患”：先检查原图、分辨率与标注；若视觉类别错，评估图像处理和模型适配；若类别对但引用错处罚规定，修 RAG；若两者都对但网页展示错，修接口/前端。数据集要按场景、时间或来源合理划分，避免同一场景的近重复图像同时进入训练与测试。

**费曼自述：** “我把整条系统拆成能测量的部分，不用一个总分掩盖‘看错图’和‘找错条款’。”

**概念闪卡：** Q：为什么要保存失败样本？A：它告诉你应改数据、模型、检索还是交付。Q：当前工作项目第一步一定是微调吗？A：先测原模型和原检索基线。

来源：你的工作项目证据清单（保存在个人学习计划工作区）。
