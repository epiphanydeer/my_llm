# 第三章 · RAG 检索增强系统（从手撕内核到工业生产）

本章专注于大模型落地中权重最高、面试必考的核心技术链路：RAG 检索增强系统。
面向 2027 社招外企 Applied MLE / LLM 应用算法工程师岗位，彻底告别“只会调 LangChain 玩 Demo”的玩具阶段，以**“可背诵因果边界 + 可闭卷手撕核心算法 + 懂分阶段排障定位”**为唯一验收标准。

## 验收完成证据（14 节全量自检清单）

本章全部 14 个小节的示例代码均已经过 Python 3.10+ 标准独立执行验证：

- 3.1 权限守卫与拒答：通过前置过滤测试、过期拦截测试与异常输入测试。

- 3.2 最小端到端 Pipeline：通过全链路切片→检索→Prompt拼接→模拟抽取与引用包含性断言。

- 3.3 滑窗切分与标点吸附：通过标点自然吸附测试、逆向字符索引恒等测试与步长死循环保护测试。

- 3.4 数值稳定余弦计算：通过同向/正交/反向向量数学校验、零向量防御与截断保护。

- 3.5 向量索引基准测试：通过 Flat 与 HNSW 结果一致性校验与参数收敛测试。

- 3.6 因果排障状态机：通过源头缺失、切片破坏、召回未中、重排截断与模型幻觉五类故障模式的单向诊断测试。

- 3.7 加权 RRF 算法：通过双路交叉排名手算理论分值吻合性测试、单路为空测试与重复防御。

- 3.8 AST 代码结构分块：通过独立函数、类方法、装饰器行号捕获测试与语法错误自愈降级。

- 3.9 检索与忠实度评测套件：通过多金标 Hit/Recall/MRR 手算吻合测试、nDCG 折损衰减与声明微平均测试。

- 3.10 自适应 Agentic 状态机：通过两步自适应收敛测试、哈希去重死循环熔断测试与步数硬限额测试。

- 3.11 项目证据审计器：通过量化提升相对计算测试、未测项显式标记与无出处吹嘘拦截测试。

- 3.12 延迟与成本分析器：通过真实总延迟分位数计算、非线性相加反证与 Token 费用测试。

- 3.13 增量更新调度器：通过哈希变动重编码测试、仅改权限免算向量测试与误删熔断保护测试。

- 3.14 多跳图路径探索器：通过有向知识链条穿透测试、全链路切片溯源断言与环路死循环剪枝测试。
