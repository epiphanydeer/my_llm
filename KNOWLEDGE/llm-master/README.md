## 如何使用

这套笔记有两层：下表的**章节导读**用于建立概念地图和快速复习（RAG 主入口已扩成详细版）；[逐篇精读](逐篇精读/索引.md)是原仓库逐篇详细整理，每篇保留技术章节，并在核心篇补充 **重要程度 → 一句话 → 例子 → 费曼自述 → 概念闪卡**。首次学习读详细版，复习时回章节导读或 RAG 速记卡。涉及代码的“会”以亲手实现和调试为准。

| 标记 | 意思 | 达标证据 |
|---|---|---|
| 🔥 必会 | 对当前大模型／多模态应用算法目标直接重要 | 能解释、写最小代码或做实验、分析失败案例 |
| ⭐ 理解 | 与后续项目或面试有关 | 能说明适用条件和取舍，项目需要时实践 |
| ◻ 略读 | 选型、工具或路线参考 | 看过目录，遇到问题知道回哪里查 |
| ⏭ 暂不学 | 新闻、迁移页、与当前目标相距较远 | 不进入复习队列 |

**记忆要求：** 记住链路、输入输出、因果关系、典型错误与指标。不要逐句背文章。每章至少做一次闭卷费曼复述；复习可放进 REVIEW（保存在个人学习计划工作区） 的 D+1、D+3、D+7、D+14、D+30 队列。

## 当前学习顺序

仓库的章节顺序是应用开发者的目录顺序；你的执行顺序仍按 方向与能力地图（保存在个人学习计划工作区）：Python/PyTorch 和 Build GPT → 模型调用与 RAG → 工作中的视觉模型适配、评测和交付 → Agent/部署深化 → 项目面试复盘。某章已经有笔记，不代表已经过关。

## 笔记规则

1. **先会解释，再背术语。** 例如“Rerank 是给已经找出的候选重新排序”，能说明它为什么救不了没召回的证据。
2. **每个概念给具体例子。** 例子围绕虚构的差旅政策问答和你的工业安全视觉＋条款检索项目，不写真实公司机密。
3. **面试答案来自实验。** 写“基线、改动、测试集、指标、失败例子”，不把原文示例数字当成自己的结果。
4. **工具和模型细节随版本核对。** 新闻、价格、API 参数在用时看官方文档。
