## 运行与验证说明

上一版 Word 转换时曾逐段检查 137 段 Python；本轮按要求侧重融合讲解，新增的第 8、9 章分节代码未重新审核。代码运行依赖各节所列环境；真实模型示例需要准备相应权重。本机使用本地 BGE embedding 和 mMARCO 重排器验证库调用，不能据此声称验证了 `bge-reranker-base` 的效果。

第 7 章的部分示例是随机模型或模拟数据流，不能视为真实 Qwen 项目结果。章节中的项目话术、数字和实验收益仅是示例，须换成自己的实际贡献与可核验数据。

## 怎样学一节

1. 先看本节要解决的问题与例子，再读原理、代码和面试内容。
2. 不看笔记回答节末闪卡，用自己的话做费曼复述。答不清就回本节找缺口。
3. 能写代码的内容要自己从空白文件写出，并保存测试、实验或错误记录。
4. 学完按 D+1、D+3、D+7、D+14、D+30 复习；复习时先闭卷回答，不重新通读全章。

**求职标准：** 简历上的技术点要有数据、基线、实验、评估和失败分析支撑。原文和本笔记提供知识，项目证据需要自己做出来。
