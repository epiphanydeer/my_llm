### 一、提出问题与真实痛点

在所有大模型手撕面试中，最容易让候选人当场翻车的两个函数调用是：
- PyTorch 中的 `view` / `reshape` 和 `transpose`。
- **经典致命错误**：
  在将维度从 `(B, T, C)` 拆成多头时，很多人直接写 `x.view(B, H, T, d_k)`！
  - 为什么这是致命的？因为内存中的连续排布顺序是按照 `T` 再到 `C` 的。如果直接 view 成 `(B, H, T, d_k)`，相当于强行把相邻时间步的特征混到了同一个头里，彻底摧毁了时序连续性！
  - **正确姿势（必须先拆后转置）**：
    先 `reshape(B, T, H, d_k)`（在特征维度切分），再 `transpose(1, 2)`（将头维度挪到时间步前面，变成 `(B, H, T, d_k)`），这样每个头内部的序列才保持了原始的时间因果顺序！
  - 在拼接合并时，也必须先 `transpose(1, 2)` 还原为 `(B, T, H, d_k)`，调用 `contiguous()` 后才能安全展平为 `(B, T, C)`！

---

### 概念主线：前面的问题如何解决

**目标：** 从 (B,T,C) 变到 (B,H,T,d)，每头算注意力，再转回 (B,T,C)。

### 二、心智模型与 ASCII 图解

```
【多头张量维度重排与内存流转图】
 输入 X: (B, T, C)
     │
     ▼ 1. 拆头先拆在特征维 C:
   (B, T, H, d_k)   [时间步 T 在前，头索引 H 在后]
     │
     ▼ 2. 转置 (1, 2):
   (B, H, T, d_k)   [头索引 H 提到最外层，每个头拥有独立的 (T, d_k) 序列！]
     │
     ▼ 3. 各头独立计算点积、Mask 与 Softmax:
   Scores: (B, H, T, T) @ Values: (B, H, T, d_k) -> Attn_Out: (B, H, T, d_k)
     │
     ▼ 4. 转置还原 (1, 2):
   (B, T, H, d_k)
     │
     ▼ 5. 内存连续化并展平拼接:
   (B, T, H * d_k) = (B, T, C)
```

### 三、核心概念与五要素表

| 五要素 | 多头注意力算子手撕关键 |
|---|---|
| **输入 (Input)** | 隐藏特征张量 $X \in \mathbb{R}^{B 	imes T 	imes C}$，头数 $H$，单头维 $d_k = C / H$。 |
| **做什么 (Process)** | 投影 $Q, K, V$；安全拆头与转置；批量计算多维点积与因果掩码；转置还原与连续拼接；输出投影 $W_o$。 |

### 四、代码动手实践与严格断言

```python
"""9.2 纯手撕工业级多头注意力算子与时序不变量断言

纯 NumPy 实现：
1. 投影 Q, K, V；
2. 规范的两步拆头：reshape(B, T, H, d_k) -> swapaxes(1, 2)；
3. 批量多维因果注意力；
4. 规范还原拼接：swapaxes(1, 2) -> reshape(B, T, C)；
5. 严格验证输出形状与多头独立性断言。
"""
import numpy as np

class ManualMultiHeadAttention:
    def __init__(self, embed_dim: int, num_heads: int, seed: int = 42):
        assert embed_dim % num_heads == 0, "embed_dim 必须能被 num_heads 整除"
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads
        
        np.random.seed(seed)
        self.W_q = np.random.randn(embed_dim, embed_dim) * 0.02
        self.W_k = np.random.randn(embed_dim, embed_dim) * 0.02
        self.W_v = np.random.randn(embed_dim, embed_dim) * 0.02
        self.W_o = np.random.randn(embed_dim, embed_dim) * 0.02

    def forward(self, x: np.ndarray, is_causal: bool = True) -> np.ndarray:
        B, T, C = x.shape
        assert C == self.embed_dim
        
        # 1. 投影生成 Q, K, V
        q = np.matmul(x, self.W_q)  # (B, T, C)
        k = np.matmul(x, self.W_k)
        v = np.matmul(x, self.W_v)
        
        # 2. 核心：严格两步拆头！
        # (a) 先在特征维切分: (B, T, H, head_dim)
        # (b) 再转置: (B, H, T, head_dim)
        q = q.reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        k = k.reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        v = v.reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        
        # 3. 批量注意力分数计算: (B, H, T, head_dim) @ (B, H, head_dim, T) -> (B, H, T, T)
        scores = np.matmul(q, k.swapaxes(-1, -2)) / np.sqrt(self.head_dim)
        
        if is_causal:
            mask = np.triu(np.ones((T, T), dtype=np.float32), k=1) * -1e9
            scores = scores + mask
            
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        
        # 4. 加权聚合: (B, H, T, T) @ (B, H, T, head_dim) -> (B, H, T, head_dim)
        attn_out = np.matmul(weights, v)
        
        # 5. 核心：严格两步还原与拼接！
        # (a) 先转置回 (B, T, H, head_dim)
        # (b) 再展平特征维为 (B, T, C)
        concat_out = attn_out.swapaxes(1, 2).reshape(B, T, C)
        
        # 6. 最终输出投影: (B, T, C) @ (C, C) -> (B, T, C)
        output = np.matmul(concat_out, self.W_o)
        return output

def self_test():
    B, T, C, H = 2, 4, 16, 4
    np.random.seed(42)
    x = np.random.randn(B, T, C)
    
    mha = ManualMultiHeadAttention(embed_dim=C, num_heads=H)
    out = mha.forward(x, is_causal=True)
    
    # 断言输出形状必须恒等于输入形状
    assert out.shape == (B, T, C), f"形状不一致: {out.shape}"
    # 验证非平凡有效数值（非全零，非 NaN）
    assert not np.isnan(out).any(), "输出包含 NaN！"
    assert np.var(out) > 0.0, "输出退化为常数！"
    print("✅ 9.2 手写多头注意力拆头与拼接断言自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：在写 PyTorch 多头注意力时，为什么 `x.transpose(1, 2)` 之后必须加 `.contiguous()` 才能调用 `.view()`？
  - **白板口述框架**：
    1. **张量步长与内存不连续**：PyTorch 底层张量是由一维内存指针加上步长（Strides）定义的。调用 `transpose` 只是在元数据层面交换了两个维度的步长，底层的物理内存并没有真正移动数据，张量变成了非连续的（Non-contiguous）。
    2. **view 算子的硬性约束**：`.view()` 函数要求张量在底层物理内存中必须是严格连续存储的。如果在非连续张量上直接调用 `.view()`，PyTorch 会抛出运行时异常 `RuntimeError: input is not contiguous`。
    3. **contiguous 的作用**：`.contiguous()` 会在内存中重新开辟一块物理空间，将数据按照当前维度顺序重新拷贝一份连续排布，从而使后续的 `.view()` 能够安全展平。
