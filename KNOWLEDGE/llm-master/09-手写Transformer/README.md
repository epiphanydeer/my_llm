## 本章主线与核心定位

“能看懂别人的代码绝不等于真正掌握，唯有从空白文件亲手写出来才算真正融会贯通。”
在顶尖大厂与外企的白板手撕面试环节中，面试官最看重的是候选人脱离大型框架黑盒、徒手推演矩阵几何维度与数值稳定性的基本功。

本章彻底摒弃第三方不可用依赖，全部代码采用**纯标准库与纯 NumPy 工业级实现**。每一小节从单一算子切入，最终组合拼接为一个能够端到端执行自回归文本生成的完整闭环系统：

1. **变长 Padding 与因果双重掩码**：从数学底层讲清 Key Masking 与 Query Masking 的本质差异，彻底杜绝除零 NaN 污染；
2. **多头张量维度重排真经**：严密剖析为什么必须“先切分特征维再转置时间维”，闭卷手撕连续内存重整与拼接；
3. **现代大模型标配进化**：从传统 ReLU MLP 全面进阶到现代大模型标配的 SwiGLU 门控前馈网络与 RMSNorm 均方根尺度归一化；
4. **端到端自回归生成闭环**：手写完整的 TinyTransformerLM，实现前向推理、尾部 Logits 提取与自回归生成循环。

## 本章高频手撕面试题速查

- **Q1: 请徒手写出多头注意力的拆头与拼接代码。**
  - *回答要点*：拆头必须 `x.reshape(B, T, H, d_k).swapaxes(1, 2)`；合并必须 `attn_out.swapaxes(1, 2).reshape(B, T, C)`。不能直接 view。
- **Q2: 为什么 RMSNorm 的 $\epsilon$ 必须加在根号内？**
  - *回答要点*：防止方差为 0 时开方发生除零异常。必须是 $\sqrt{	ext{mean}(x^2) + \epsilon}$。
- **Q3: 为什么大模型自回归生成每一步只取最后一个位置的 Logits？**
  - *回答要点*：自回归是在给定历史前文的条件下预测“下一个新词”。根据因果依赖，只有序列最后一个位置聚合了前面的全量上下文，因此只需提取最后一个位置的 Logits 做采样。
