### 一、提出问题与真实痛点

在很多实际工程中，把单独写好的 MultiHeadAttention、RMSNorm、SwiGLU FFN 拼成一个完整的 Block 时，最容易出现以下三大工程隐患：
1. **残差分支与归一化顺序错位**：把原本应该加到输入上的残差，错误加到了归一化后的临时变量上；
2. **掩码传递缺失**：在外层未透传因果掩码或 Padding 掩码，导致多层堆叠后时序全面泄漏；
3. **参数更新时梯度断裂**：未保持纯浮点张量传递。
本节目标：将前面手写的三个独立算子无缝组装为一个自包含、严密断言、且支持深层堆叠的完整工业级 Pre-LN Transformer Block！

---

### 概念主线：前面的问题如何解决

**目标：** 把注意力、Norm、FFN 和两次残差按选定 Pre-Norm/Post-Norm 顺序接起来，明确输入/输出都为 (B,T,C)。

### 三、核心概念与五要素表

| 五要素 | 完整 Pre-LN Transformer Block 架构 |
|---|---|
| **输入 (Input)** | 隐藏特征张量 $X \in \mathbb{R}^{B 	imes T 	imes C}$，因果掩码开关 `is_causal`。 |
| **做什么 (Process)** | 第 1 阶段：$	ext{Norm}_1(X) 	o 	ext{MHA} 	o X + 	ext{MHA\_Out}$；第 2 阶段：$	ext{Norm}_2(H) 	o 	ext{FFN} 	o H + 	ext{FFN\_Out}$。 |
| **输出 (Output)** | 更新后的隐藏特征张量 $Y \in \mathbb{R}^{B 	imes T 	imes C}$。 |
| **哪里出错 (Failure Modes)** | 1. 混淆两次残差加和的主干来源；2. 形状不闭环。 |
| **参数影响 (Parameters)** | 隐藏维度 $C$ 与多头数 $H$、FFN 中间升维比率 $R$ 共同决定单层计算量与参数量。 |

### 四、代码动手实践与严格断言

```python
"""9.5 纯手撕工业级 Pre-LN Transformer Block 模块

纯 NumPy 实现：
1. 内置手写 RMSNorm；
2. 内置手写因果 MultiHeadAttention；
3. 内置手写 SwiGLU 门控前馈网络；
4. 严格 Pre-LN 双重残差拓扑；
5. 严格验证维度闭环与多层级联断言。
"""
import numpy as np

def silu(x: np.ndarray) -> np.ndarray:
    return x / (1.0 + np.exp(-np.clip(x, -20.0, 20.0)))

class PureRMSNorm:
    def __init__(self, dim: int, eps: float = 1e-6):
        self.eps = eps
        self.gamma = np.ones(dim, dtype=np.float32)

    def forward(self, x: np.ndarray) -> np.ndarray:
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return (x / rms) * self.gamma

class PureTransformerBlock:
    def __init__(self, channels: int = 16, num_heads: int = 4, ffn_hidden: int = 32, seed: int = 42):
        self.channels = channels
        self.num_heads = num_heads
        self.head_dim = channels // num_heads
        
        np.random.seed(seed)
        self.norm1 = PureRMSNorm(channels)
        self.norm2 = PureRMSNorm(channels)
        
        # MHA 投影矩阵
        self.W_q = np.random.randn(channels, channels) * 0.02
        self.W_k = np.random.randn(channels, channels) * 0.02
        self.W_v = np.random.randn(channels, channels) * 0.02
        self.W_o = np.random.randn(channels, channels) * 0.02
        
        # SwiGLU FFN 矩阵
        self.w_gate = np.random.randn(channels, ffn_hidden) * 0.02
        self.w_up = np.random.randn(channels, ffn_hidden) * 0.02
        self.w_down = np.random.randn(ffn_hidden, channels) * 0.02

    def _mha(self, x: np.ndarray, is_causal: bool = True) -> np.ndarray:
        B, T, C = x.shape
        q = np.matmul(x, self.W_q).reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        k = np.matmul(x, self.W_k).reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        v = np.matmul(x, self.W_v).reshape(B, T, self.num_heads, self.head_dim).swapaxes(1, 2)
        
        scores = np.matmul(q, k.swapaxes(-1, -2)) / np.sqrt(self.head_dim)
        if is_causal:
            mask = np.triu(np.ones((T, T), dtype=np.float32), k=1) * -1e9
            scores += mask
            
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        attn_out = np.matmul(weights, v).swapaxes(1, 2).reshape(B, T, C)
        return np.matmul(attn_out, self.W_o)

    def _ffn(self, x: np.ndarray) -> np.ndarray:
        gate = silu(np.matmul(x, self.w_gate))
        up = np.matmul(x, self.w_up)
        return np.matmul(gate * up, self.w_down)

    def forward(self, x: np.ndarray, is_causal: bool = True) -> np.ndarray:
        # Pre-LN 关卡 1: 注意力与第一条残差公路
        h = x + self._mha(self.norm1.forward(x), is_causal=is_causal)
        # Pre-LN 关卡 2: FFN 与第二条残差公路
        out = h + self._ffn(self.norm2.forward(h))
        return out

def self_test():
    B, T, C = 2, 5, 16
    np.random.seed(42)
    x = np.random.randn(B, T, C)
    
    block = PureTransformerBlock(channels=C, num_heads=4, ffn_hidden=32)
    out = block.forward(x, is_causal=True)
    
    # 核心几何不变量断言：输入输出形状严格一致！
    assert out.shape == (B, T, C), f"形状不一致: {out.shape}"
    # 验证非平凡变换
    assert not np.allclose(out, x), "Block 输出与输入完全相同（无更新）！"
    print("✅ 9.5 纯手写 Pre-LN Transformer Block 完整拓扑自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：如果在测试时发现模型输出全部变成了 NaN，在 Transformer Block 中应该怎么按顺序二分排查？
  - **白板口述框架**：
    1. **排查 Softmax 分母是否除零**：检查是否有全被 Mask 掉的无效行（全 $-1e9$），若有，检查 Softmax 前是否有极值裁剪与防除零平滑项。
    2. **排查 LayerNorm / RMSNorm 方差是否开方除零**：检查激活值是否出现全 0 向量，确认 $\sqrt{\sigma^2 + \epsilon}$ 中的 $\epsilon$ 是否丢失或设得过小（如小于浮点下溢下限）。
    3. **排查 FFN 激活溢出**：检查中间中间矩阵乘法是否梯度过大导致数值超出 FP16 范围（65504），确认是否需要引入激活值裁剪（Gradient Clipping / Activation Clamping）。
