## 本章主线与应用岗核心定位

在针对中国境内外企「Applied MLE / LLM 应用算法工程师」的面试中，Agent 是仅次于 RAG 的核心高频考点。面试官考察 Agent 的核心绝不是“你会不会调 AutoGen / LangChain / CrewAI 跑通一个 Demo”，而是考察你对决策闭环控制、确定性与灵活性权衡、失败防御与状态机底层流转的真正掌控力：

- 从零手撕核心控制流：能否脱离重型框架，纯 Python 写出具备停止条件、异常拦截、参数校验的 ReAct 循环内核与状态机；

- 确定性工程防御：如何防范模型失控死循环（连续相同调用与交替死循环双模熔断）、如何做工具权限沙箱隔离、如何做原子轮次滑动窗口记忆压缩；

- 架构选型与系统边界：什么时候该用确定性 DAG 工作流，什么时候才需要自主 Agent；如何向外对接标准 MCP 协议，如何实现声明级事实核验与幻觉阻断。

## 本章重点面试题速查

- Q1: 什么时候选确定性 Workflow，什么时候选自主 Agent？

- 回答要点：业务逻辑固定、容错率低（如安全隐患审核放行）选确定性状态机工作流；多跳复杂推理、数据源不确定选自主 Agent，但外层必须加装硬步数与双模熔断保护。

- Q2: Agent 线上死循环停不下来怎么排障？

- 回答要点：区分“同参数连续死重试”与“多工具交替振荡”；利用字典序排序 JSON 生成确定性调用指纹，结合滑动窗口实现模式匹配即时熔断。

- Q3: 如何解决多角色 Agent 上下文爆炸与信息污染？

- 回答要点：践行最小权限与信息最小化原则（Least Privilege），跨角色流转严禁传递完整长对话历史，通过强类型受控字段投影仅传递必要摘要与决策结果。

- Q4: 工具执行发生异常时，如何设计自愈与降级机制？

- 回答要点：对异常分级，网络抖动采用带抖动的指数退避；参数解析错误将错误栈回传给模型请求重构；超过重试上限后触发降级策略转人工。

## 学习建议与复习打卡路线

- 第一阶段（地基篇 Level 1~5）：吃透单智能体闭环。重点手撕 4.1 状态机、4.4 ReAct 内核与 4.5 记忆滑动窗口，闭卷能画出数据流与消息栈。

- 第二阶段（工程篇 Level 6~10）：掌握生产级鲁棒性。重点攻克 4.6 失败恢复、4.7 离线评测与 4.9 DAG 调度引擎，理解工业级与玩具代码的本质差异。

- 第三阶段（高级篇 Level 11~15）：具备复杂系统架构能力。掌握 4.11 跨角色投影、4.14 死循环熔断器与 4.15 声明级门控，在外企高阶面试中展现架构前瞻性。
