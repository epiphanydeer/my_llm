# 第四章 · Agent 智能体与工具调用（从核心内核到多角色编排）

本章专注于大模型应用落地的第二大核心支柱：Agent 智能体系统。
面向 2027 社招外企 Applied MLE / LLM 应用算法工程师岗位，告别玩具式的 Prompt 堆砌，以**“从零手撕 ReAct 循环内核 + 严格工具 Schema 校验 + 上下文原子保护 + 多重防死循环熔断”**为唯一验收标准。

## 验收完成证据（10 节全量自检清单）

本章全部 10 个小节的示例代码均已在 Python 3.10+ 标准独立执行验证：

- 4.1 最小闭环状态机：通过 O-T-A 状态流转测试、硬步数熔断测试与空目标拦截测试。

- 4.2 确定性安全工作流：通过无证施工硬驳回测试、重大风险特批路由测试与低风险秒级自动通过测试。

- 4.3 工具注册表与安全沙箱：通过合法调用测试、越权调用拦截测试、参数注入额外属性拦截测试与重复键拦截测试。

- 4.4 手撕 ReAct 循环内核：通过两轮顺利收敛测试、动作签名哈希防死循环测试与输出物理截断容错测试。

- 4.5 原子轮次滑动窗口：通过整轮完整性测试、系统提示词置顶锁死测试与严苛预算下整轮安全淘汰测试。

- 4.6 错误分级弹性执行器：通过暂时故障指数退避自愈测试、权限不足致命错误立即退出断言与配额耗尽测试。

- 4.7 离线轨迹评测套件：通过任务完成率手算吻合测试、步骤效率过滤测试与失败归因直方图分布校验。

- 4.8 JSON-RPC 2.0 MCP 分发器：通过 tools/list 工具发现测试、tools/call 合法调用测试与标准协议错误码拦截测试。

- 4.9 轻量 DAG 任务调度引擎：通过拓扑排序全链路执行测试、上游失败下游级联跳过测试与死锁环路静态拦截测试。

- 4.10 多角色协作与返工熔断：通过带审查意见的单轮自愈交付测试与零返工严苛模式下的安全移交人工断言测试。
