## 与面试、代码的关系

面试先说明输入、处理、输出、故障和参数，再用本地示例解释权限、验证和恢复；第 4 章已有的 Agent 循环与协议不在此重复展开。

## 附录完成标准

能画出任务闭环；说清 Prompt、工具、MCP、Skill、Hook 和 Harness 各负责什么；自己写出有权限检查、预算、停止条件和日志的最小循环。产品专有命令用时查官方文档，不作为背诵任务。
