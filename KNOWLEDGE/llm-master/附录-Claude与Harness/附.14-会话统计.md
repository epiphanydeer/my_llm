### 概念与数据流

| 五要素 | 说明 |
| --- | --- |
| 输入 | 人工分类的会话 ID 和标签目录。 |
| 做什么 | 检查唯一性、标签有效性，然后计数。 |
| 输出 | 各标签样本数，包括零计数类别。 |
| 哪里出错 | 重复会话、未知标签、缺失样本或标签口径变化导致统计失真。 |
| 参数影响 | 采样窗口、标签定义与标注一致性影响解释范围。 |

### 面试追问

【⭐ 理解】会话中某类问题多就说明工具效果差吗？ 结论：不能直接推断。还需对照任务难度、采样方式、完成结果和其他因素。

【⭐ 理解】只有成功会话的统计能代表全部用户吗？ 结论：不能。成功样本可能存在选择偏差，要说明采集范围和缺失。

【⭐ 理解】两次统计的分类占比突变怎么排查？ 结论：先检查样本与口径。比较采样窗口、标签版本和重复率，再分析业务变化。

### 故障模式与排障

- 同一会话重复计数：按稳定 ID 去重并说明去重口径。

- 新标签被悄悄丢弃：检查标签目录并显式处理未知值。

- 分布发生变化但口径也变了：固定或映射标签后比较，并保留样本量。

### 工程 trick 与坑

- 计数样本是虚构数据，不复述或验证原镜像文章的真实规模。

- 分类频率不等于成功率，相关性也不能直接说明因果。

- 真实会话可能包含敏感信息，收集和保留要符合具体场景权限与政策。

### Toy code：虚构会话分组计数

运行前提：Python 3.10+，标准库，不读取真实会话。

```python
"""对虚构会话样本按人工标签计数，不推断总体或因果。"""
from collections import Counter
from dataclasses import dataclass


@dataclass(frozen=True)
class Session:
    """会话标识和一个人工归类标签。"""
    session_id: str
    category: str


def summarize(rows: list[Session], categories: set[str]) -> dict[str, int]:
    """验证 ID 唯一和标签在目录内，返回各类计数。"""
    if not categories or any(not isinstance(x, str) or not x.strip() for x in categories):
        raise ValueError('标签目录不能为空')
    if not rows:
        raise ValueError('没有样本，不能生成分布')
    seen: set[str] = set()
    counts: Counter[str] = Counter()
    for row in rows:
        if not row.session_id.strip() or row.session_id in seen:
            raise ValueError('会话 ID 不能为空或重复')
        if row.category not in categories:
            raise ValueError('存在未知标签')
        seen.add(row.session_id)
        counts[row.category] += 1
    result = {category: counts[category] for category in sorted(categories)}
    assert sum(result.values()) == len(rows)
    return result


def main() -> None:
    """覆盖零计数、未知标签、空数据和重复 ID。"""
    labels = {'检索', '编辑', '其他'}
    rows = [Session('s1', '检索'), Session('s2', '编辑'), Session('s3', '检索')]
    assert summarize(rows, labels) == {'其他': 0, '检索': 2, '编辑': 1}
    for bad in ([], rows + rows[:1], [Session('s4', '未知')]):
        try:
            summarize(bad, labels)
        except ValueError:
            pass
        else:
            raise AssertionError('空样本、重复 ID 或未知标签必须拒绝')
    print('虚构样本 n=3，标签计数:', summarize(rows, labels))
    print('样本非随机；标签不是效果评价，也不能解释因果。')


if __name__ == '__main__':
    main()
```

逐段理解。 Session 存 ID 和分类；summarize 验证标签及唯一性并包含零计数；自检覆盖异常输入。

### 这段代码怎么在面试里讲

- 不变量：ID 唯一、每条标签属于目录，各类计数总和等于样本数。

- 关键过程：先检查数据质量，再逐类计数并明确展示 n。

- 边界与坑：样本量只有三条且非随机，不能推广或解释因果。

### 本节收尾：费曼自述与闪卡

费曼自述： 统计前先确定样本、标签和分母；频数只能描述这批样本，不自动证明效果或因果。

- 问：三条虚构数据能代表真实用户吗？答：不能。

- 问：分类计数总和应该等于什么？答：有效样本数。

- 问：标签频率就是成功率吗？答：不是。

- 问：两期结果比较前先核对什么？答：采样和标签口径。
