## 附.15 Harness 面试：贡献与证据【◻ 按需】

〔补充自原仓库镜像〕〔本次新补，参考当前面试趋势〕

目标 + 例子。 回答工程项目题时说清任务、个人动作、证据和边界。特别是论文与公司项目，要区分本人贡献与团队成果。

### 概念与数据流

| 五要素 | 说明 |
| --- | --- |
| 输入 | 工作内容、本人角色、证据描述与可选计数。 |
| 做什么 | 检查叙述字段是否完整，并校验比率的分子分母。 |
| 输出 | 无指标返回空，有有效计数则返回比率。 |
| 哪里出错 | 把团队成果说成本人贡献、缺分母或把格式校验误当事实核查。 |
| 参数影响 | 样本范围、度量口径、基线和时间窗口决定指标含义。 |

### 面试追问

【⭐ 理解】如何介绍没有完整上线的项目？ 结论：如实说明阶段与实际贡献。区分自己实现的部分、借助工具完成的部分和后续未验证项。

【⭐ 理解】如何证明性能提升？ 结论：说明基线、分母和对照条件。若没有有效测量，就说明尚未验证，不编造数字。

【⭐ 理解】面试官追问某个指标算错怎么办？ 结论：回到原始记录和计算口径。核实分子分母、数据切分、去重和统计时间窗。

### 故障模式与排障

- 贡献归属混淆：按任务拆开本人、他人和 AI 辅助的工作，并准备证据。

- 只报百分比：补充分子分母、基线、数据范围和实验条件。

- 证据字段填了却无法复现：核查实际日志和版本；字段合规不证明真实性。

### 工程 trick 与坑

- 本例只是格式检查，不读取或验证实际项目材料。

- 涉及保密项目时用脱敏数据、流程和经允许披露的成果。

- 本人的论文贡献应按实际情况说明，不将他人的编码工作归到自己。

### Toy code：叙述字段与比率校验

运行前提：Python 3.10+，标准库；所有示例均为虚构经历。

```python
"""检查虚构项目叙述的贡献和数值证据字段，不替用户编造经历。"""
from dataclasses import dataclass
import math


@dataclass(frozen=True)
class Claim:
    """工作内容、个人角色及可选的指标分子和分母。"""
    work: str
    role: str
    evidence: str
    numerator: int | None = None
    denominator: int | None = None


def check(claim: Claim) -> float | None:
    """缺角色或证据则拒绝；提供比率时要求完整有效的计数。"""
    if not all(isinstance(x, str) and x.strip() for x in (claim.work, claim.role, claim.evidence)):
        raise ValueError('工作、个人角色和证据均须填写')
    a, b = claim.numerator, claim.denominator
    if a is None and b is None:
        return None
    if any(isinstance(x, bool) or not isinstance(x, int) for x in (a, b)):
        raise ValueError('分子和分母须同时为整数')
    assert a is not None and b is not None
    if b <= 0 or a < 0 or a > b:
        raise ValueError('计数超出有效范围')
    result = a / b
    assert math.isfinite(result) and 0 <= result <= 1
    return result


def main() -> None:
    """检验有无数字的描述、缺证据与非法分母。"""
    item = Claim('虚构检索实验', '独立实现评测脚本', '本地记录', 3, 5)
    assert check(item) == 0.6
    assert check(Claim('文献整理', '参与阅读', '笔记')) is None
    for bad in (Claim('工作', '', '记录'), Claim('工作', '参与', ''),
                Claim('工作', '参与', '记录', 3, 0), Claim('工作', '参与', '记录', 1, None)):
        try:
            check(bad)
        except ValueError:
            pass
        else:
            raise AssertionError('缺证据或无效数字必须拒绝')
    print('虚构叙述格式自检通过；字段合法不代表事实已核实。')


if __name__ == '__main__':
    main()
```

逐段理解。 Claim 保存工作、角色和证据；check 仅检查字段及数值范围；自检覆盖缺项和非法分母。

### 这段代码怎么在面试里讲

- 不变量：叙述字段非空，若计算比率则分母大于零且分子在有效范围。

- 关键过程：先检查证据字段，再按完整分子分母计算；缺数值不强行构造。

- 边界与坑：示例不能验证证据真实性；真实面试须回看本人记录和保密边界。

### 本节收尾：费曼自述与闪卡

费曼自述： 项目回答要让面试官知道我做了什么、依据是什么、哪些结果还没证实；没有证据就不要编数字。

- 问：格式校验通过是否证明经历真实？答：不是。

- 问：指标应说明什么？答：基线、分子分母、数据和条件。

- 问：论文编码贡献少如何说？答：如实区分自己的贡献。

- 问：尚未上线如何回答？答：说明当前阶段与未验证部分。
