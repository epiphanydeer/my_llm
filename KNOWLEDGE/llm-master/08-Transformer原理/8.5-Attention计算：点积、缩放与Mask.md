### 一、提出问题与真实痛点

在手撕注意力机制时，有两个极为致命的经典八股与翻车点：
1. **为什么要除以 $\sqrt{d_k}$？不除会怎么样？**
   - 假设向量 $Q$ 和 $K$ 的各个分量是独立同分布的标准正态分布（均值 0，方差 1）。
   - 两者的点积是 $d_k$ 个乘积之和，由概率统计方差可加性可知，点积结果的方差为 $d_k$，标准差为 $\sqrt{d_k}$！
   - 当特征维度 $d_k$ 很大（如 64、128）时，点积数值可能飙升到几十甚至上百。
   - **致命后果**：经过 Softmax 之后，最大值对应的概率无限接近 1.0，其余全为 0。函数进入饱和区，**Softmax 的导数几乎完全归零，引发严重的梯度消失（Gradient Vanishing）**！除以 $\sqrt{d_k}$ 能够将方差重新缩放回 1.0，保证梯度平稳流动。
2. **因果 Mask 为什么要在 Softmax 之前加，而不是之后？**
   - 如果在 Softmax 之后把未来位置的概率置 0，剩下的过去位置概率和就不等于 1 了，破坏了概率分布公理！必须在 Softmax 之前向未来位置加上 $-\infty$（代码中用 $-1e9$），这样经过 $e^{-\infty} = 0$，归一化分母自动只由过去位置构成。

---

### 概念主线：前面的问题如何解决

**一句话：** 当前 token 的 Query 与各位置 Key 比较，得到注意力分数；分数经缩放、mask、softmax 后作为权重，对各位置 Value 加权求和。

### 三、核心概念与五要素表

| 五要素 | 缩放点积注意力计算核心 |
|---|---|
| **输入 (Input)** | 投影张量 $Q, K, V \in \mathbb{R}^{B 	imes T 	imes d}$，因果掩码标志 `is_causal`。 |
| **做什么 (Process)** | 点积 $Q K^T$；除以 $\sqrt{d}$ 缩放；叠加因果掩码；数值稳定 Softmax；乘上 $V$。 |
| **输出 (Output)** | 上下文表征张量 `[B, T, d]` 与注意力权重概率矩阵 `[B, T, T]`。 |
| **哪里出错 (Failure Modes)** | 1. 忘记缩放 $\sqrt{d}$ 导致大模型训练初期梯度暴死；2. 因果 Mask 方向反向（变成了只能看未来，看不见过去）。 |
| **参数影响 (Parameters)** | 缩放因子 $1/\sqrt{d}$ 是注意力数值稳定的定海神针。 |

### 四、代码动手实践与严格断言

```python
"""8.5 纯手写因果缩放点积注意力与方差缩放断言

纯 NumPy 实现：
1. 计算点积并除以 sqrt(d)；
2. 构造因果掩码 (-1e9)；
3. 数值稳定 Softmax；
4. 严格断言：未来位置权重精确等于 0，且每行概率和精确等于 1.0。
"""
import numpy as np

def scaled_dot_product_attention(
    Q: np.ndarray,
    K: np.ndarray,
    V: np.ndarray,
    is_causal: bool = True
) -> tuple[np.ndarray, np.ndarray]:
    """
    Q, K, V: 形状为 (B, T, d)
    """
    B, T, d = Q.shape
    # 1. 矩阵乘法点积: (B, T, d) @ (B, d, T) -> (B, T, T)
    scores = np.matmul(Q, np.swapaxes(K, -1, -2)) / np.sqrt(d)
    
    # 2. 因果 Mask
    if is_causal:
        # 上三角 (k=1) 填入 -1e9
        mask = np.triu(np.ones((T, T), dtype=np.float32), k=1) * -1e9
        scores = scores + mask
        
    # 3. 数值稳定 Softmax
    max_scores = np.max(scores, axis=-1, keepdims=True)
    exp_scores = np.exp(scores - max_scores)
    attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
    
    # 4. 加权求和输出: (B, T, T) @ (B, T, d) -> (B, T, d)
    output = np.matmul(attn_weights, V)
    return output, attn_weights

def self_test():
    np.random.seed(42)
    B, T, d = 2, 4, 16
    Q = np.random.randn(B, T, d)
    K = np.random.randn(B, T, d)
    V = np.random.randn(B, T, d)
    
    out, weights = scaled_dot_product_attention(Q, K, V, is_causal=True)
    
    # 验证形状
    assert out.shape == (B, T, d)
    assert weights.shape == (B, T, T)
    
    # 严格因果断言：未来位置的权重必须严格小于 1e-7（本质为 0）
    for b in range(B):
        for i in range(T):
            for j in range(i + 1, T):
                assert weights[b, i, j] < 1e-7, f"因果泄露！位置 ({i}, {j}) 权重非零: {weights[b, i, j]}"
                
    # 严格概率断言：每行概率和等于 1.0
    row_sums = np.sum(weights, axis=-1)
    assert np.allclose(row_sums, 1.0, atol=1e-5), "Softmax 行和不等于 1.0！"
    print("✅ 8.5 纯手写因果缩放点积注意力自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：除以 $\sqrt{d}$ 的数学推导是什么？请在白板上推导方差。
  - **白板口述框架**：
    设向量 $q = [q_1, \dots, q_d]$ 和 $k = [k_1, \dots, k_d]$，且每个分量独立同分布，期望 $E[q_i] = E[k_i] = 0$，方差 $D[q_i] = D[k_i] = 1$。
    则点积 $S = q \cdot k = \sum_{i=1}^d q_i k_i$：
    1. 期望：$E[q_i k_i] = E[q_i] E[k_i] = 0$，所以 $E[S] = 0$。
    2. 方差：$D[q_i k_i] = E[(q_i k_i)^2] - (E[q_i k_i])^2 = E[q_i^2] E[k_i^2] - 0 = 1 	imes 1 = 1$。
    3. 由独立随机变量和的方差性质：$D[S] = D[\sum_{i=1}^d q_i k_i] = \sum_{i=1}^d D[q_i k_i] = d$。
    4. 标准差为 $\sigma = \sqrt{D[S]} = \sqrt{d}$。
    因此，当 $d$ 很大时，点积的数值波动范围会被拉大到 $[-\sqrt{d}, \sqrt{d}]$ 级别。如果不除以 $\sqrt{d}$，Softmax 的输出将出现极值，梯度迅速饱和趋近于 0。除以 $\sqrt{d}$ 后，方差重新归一化为 1，有效维持了平稳反向传播梯度。
