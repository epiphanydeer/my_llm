## 本章主线与核心定位

在针对外企与顶级大厂「Applied MLE / 大模型应用算法工程师」的技术面试中，Transformer 的底层机制是技术总监进行深挖（Deep Dive）的必考基本盘。本章彻底摒弃市面空洞的公式速记，建立起**心智模型优先、张量几何流转、纯手写数值断言**的三位一体硬核知识库：

1. **从零追踪张量形状流转**：从原始自然语言字符串、Tokenizer 编码、Embedding 查表，流经堆叠 Block，直到 LM Head 映射为 Logits 概率分布；
2. **QKV 几何解耦与数学推导**：为什么语言模型必须打破对称性？为什么必须除以 $\sqrt{d_k}$ 防范 Softmax 梯度饱和？因果 Mask 为什么必须加在 Softmax 前？
3. **现代大模型标配进化树**：从绝对正弦位置编码进化到 RoPE（旋转位置编码）的相对几何不变性；从 Post-LN 进化到 Pre-LN / RMSNorm 的深层梯度高速公路；
4. **推理高并发的核心秘密**：KV Cache 如何将自回归生成的计算复杂度从 $O(N^2)$ 降维到 $O(N)$？如何精准手算一个 7B 模型的显存开销。

## 本章高频面试题速查

- **Q1: 为什么自注意力机制计算时要除以 $\sqrt{d_k}$？**
  - *回答要点*：若不缩放，高维点积方差会膨胀至 $d_k$。在 Softmax 作用下，数值会过大导致概率分布极端极化进入饱和区，引起反向传播梯度几乎完全归零（梯度消失）。
- **Q2: 为什么大语言模型几乎全采用 Decoder-only 架构？**
  - *回答要点*：预训练自回归 Next-token Prediction 具备通用泛化性；Decoder-only 架构无交叉注意力通信开销，分布式扩展极其简洁；单路 KV Cache 加速机制最干净。
- **Q3: 为什么现代主流模型（LLaMA/Qwen/DeepSeek）都采用 Pre-LN 而非原始 Post-LN？**
  - *回答要点*：Post-LN 残差加和后才做归一化，深层梯度极易发散爆炸；Pre-LN 在进入子层前先做归一化，残差连接为主干提供了无阻碍的恒等梯度直通通道，千亿训练更加稳定。
- **Q4: RoPE 是绝对位置编码还是相对位置编码？**
  - *回答要点*：RoPE 兼具两者的优势。在实现上，它通过单个 Token 的绝对位置 $m$ 乘以旋转矩阵注入；在数学特性上，两个向量的点积展开后绝对坐标抵消，严格只保留相对距离 $n - m$。
