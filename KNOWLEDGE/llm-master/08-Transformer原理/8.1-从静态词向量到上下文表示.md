### 一、提出问题与真实痛点

在传统的自然语言处理（如 Word2Vec、GloVe）中，每个词在词表中对应一个固定不变的向量。
- **致命缺陷（一词多义与语境失真）**：
  - 句子 A：“我刚刚在果园摘了一个红富士**苹果**。”
  - 句子 B：“**苹果**今天发布了搭载 M4 芯片的 MacBook Pro。”
  - 句子 C：“**苹果**肌下垂可以通过医美提升改善。”
  在 Word2Vec 中，“苹果”永远查表得到同一个向量 `[0.34, -0.82, 0.11, ...]`。下游模型根本无法区分它是水果、数码科技巨头、还是人体面部解剖结构！
- **Transformer 的破局之道**：
  引入**自注意力机制 (Self-Attention)**。静态词嵌入（Token Embedding）只作为最底层的静态输入查表；当张量流经 Transformer 每一层 Block 时，当前词会主动与序列中其他词计算注意力权重并聚合信息。“苹果”结合上文的“摘”、“红富士”，其动态表示被拉向水果特征空间；结合“发布”、“MacBook”，其动态表示被拉向科技公司流形。

---

### 概念主线：前面的问题如何解决

**一句话：** 文本经过 tokenizer 变成 token ID；Embedding 表把每个 ID 映射到 C 维向量；模型还需要位置信息，然后进入多层 Block。

### 三、核心概念与五要素表

| 五要素 | 因果上下文化表示组件 |
|---|---|
| **输入 (Input)** | 序列 Token ID 张量 `[B, T]`，词表容量 `vocab_size`，隐藏维度 `C`。 |
| **做什么 (Process)** | 查表得到静态词向量；叠加位置编码；执行因果自注意力聚合前文信息；残差连接与归一化。 |
| **输出 (Output)** | 上下文动态隐藏态张量 `[B, T, C]`。 |
| **哪里出错 (Failure Modes)** | 1. 未加因果 Mask 导致后文信息泄漏（时空穿越）；2. 忘记加位置编码导致“我打你”和“你打我”向量完全一致。 |
| **参数影响 (Parameters)** | 隐藏维度 `C` 越大模型容量越高，但矩阵乘法计算量呈平方级上升。 |

### 四、代码动手实践与严格断言

```python
"""8.1 静态词向量向动态上下文表示演变验证器

自包含纯 NumPy 实现：
1. 静态词表 Embedding 查表；
2. 基础多头自注意力上下文特征聚合；
3. 严格断言：同一个 Token 在不同上下文语境下输出的动态表示向量余弦相似度必须产生显著偏离！
"""
import numpy as np

def cosine_similarity(v1: np.ndarray, v2: np.ndarray, eps: float = 1e-9) -> float:
    dot = np.dot(v1, v2)
    norm = (np.linalg.norm(v1) * np.linalg.norm(v2)) + eps
    return float(dot / norm)

class ToyContextualEmbedding:
    def __init__(self, vocab_size: int = 100, embed_dim: int = 16, seed: int = 42):
        np.random.seed(seed)
        self.embed_dim = embed_dim
        # 静态词嵌入表: (vocab_size, embed_dim)
        self.embedding_table = np.random.randn(vocab_size, embed_dim) * 0.1
        # 模拟注意力线性投影 W_q, W_k, W_v
        self.W_q = np.random.randn(embed_dim, embed_dim) * 0.1
        self.W_k = np.random.randn(embed_dim, embed_dim) * 0.1
        self.W_v = np.random.randn(embed_dim, embed_dim) * 0.1

    def forward(self, token_ids: list[int]) -> np.ndarray:
        """输入 token id 列表，输出经过因果注意力的上下文表示 (T, embed_dim)"""
        T = len(token_ids)
        # 1. 查表获取静态向量: (T, C)
        X = self.embedding_table[token_ids]
        
        # 2. 投影为 Q, K, V
        Q = np.dot(X, self.W_q)  # (T, C)
        K = np.dot(X, self.W_k)  # (T, C)
        V = np.dot(X, self.W_v)  # (T, C)
        
        # 3. 计算注意力分数 Q K^T / sqrt(d)
        scores = np.dot(Q, K.T) / np.sqrt(self.embed_dim)  # (T, T)
        
        # 4. 因果 Mask (未来位置设为 -1e9)
        causal_mask = np.triu(np.ones((T, T)), k=1) * -1e9
        scores += causal_mask
        
        # 5. Softmax 归一化
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        
        # 6. 加权求和输出上下文表示
        context_out = np.dot(attn_weights, V)  # (T, C)
        return context_out

def self_test():
    encoder = ToyContextualEmbedding(vocab_size=100, embed_dim=16)
    
    # 模拟单词 ID: 目标词 "苹果" = ID 10
    # 语境 A: "新鲜 水果 苹果" = [21, 22, 10]
    # 语境 B: "电脑 手机 苹果" = [31, 32, 10]
    seq_fruit = [21, 22, 10]
    seq_tech = [31, 32, 10]
    
    # 1. 验证静态词向量：两次查表得到的静态向量完全一致
    static_apple_1 = encoder.embedding_table[10]
    static_apple_2 = encoder.embedding_table[10]
    assert np.array_equal(static_apple_1, static_apple_2), "静态词向量查表必须完全一致！"
    
    # 2. 验证动态上下文表示：因果注意力后，最后一个位置的向量必须产生语义偏移
    out_fruit = encoder.forward(seq_fruit)
    out_tech = encoder.forward(seq_tech)
    
    dynamic_apple_fruit = out_fruit[-1]
    dynamic_apple_tech = out_tech[-1]
    
    sim = cosine_similarity(dynamic_apple_fruit, dynamic_apple_tech)
    print(f"8.1 自检: 同一词在不同语境下的动态余弦相似度 = {sim:.4f}")
    assert sim < 0.95, "动态上下文表示未发生语境分化！"
    print("✅ 8.1 静态词向量到动态上下文表示自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：Word2Vec 与 Transformer 的核心区别是什么？
  - **白板口述框架**：
    1. **静态 vs 动态**：Word2Vec 是离线查表，一个 token 映射到一个固定向量，无法建模一词多义；Transformer 的 Embedding 只是起点，经过多层 Self-Attention 矩阵乘法后，每个 token 聚合了周围上下文，输出的是高维动态表征。
    2. **局部窗口 vs 全局因果关联**：Word2Vec 依靠固定大小的滑动窗口（如 window=5）优化共现几率；Transformer 每一层都可以直接在注意力矩阵中建立跨越数百乃至上万 token 的长程依赖，解决了 RNN 梯度消失与遗忘问题。
