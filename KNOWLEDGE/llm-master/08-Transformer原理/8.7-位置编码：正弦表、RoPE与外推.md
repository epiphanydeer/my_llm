### 一、提出问题与真实痛点

自注意力机制天生是“置换不变性（Permutation Invariant）”的。
- **痛点**：如果不加任何位置信息，句子“小红打了小明”和“小明打了小红”，所有词的点积交互完全对称，模型输出的特征完全一样！
- **发展三代技术脉络**：
  1. **第一代：绝对位置编码（Absolute PE / Sinusoidal）**：2017 原始 Transformer，使用正弦余弦函数计算固定绝对坐标向量直接加到 Embedding 上。缺点：无法有效泛化到训练长度之外，外推能力弱。
  2. **第二代：可学习位置编码（Learnable PE）**：BERT / GPT-2 使用一个可训练的位置向量矩阵直接查表相加。缺点：同样无法外推超过训练时设置的最大长度。
  3. **第三代：旋转位置编码（RoPE, Rotary Position Embedding）**：现代主流大模型（LLaMA、DeepSeek、Qwen、Mistral）的绝对统治级标配！通过将高维向量两两切分成 2D 坐标系，在复数平面上乘以旋转矩阵。**它拥有精妙的数学性质：绝对位置编码的形式，带来了天然的相对位置内积感知，且天然支持长文本 RoPE 插值外推！**

### 概念主线：前面的问题如何解决

### 二、心智模型与 ASCII 图解

```
【RoPE (旋转位置编码) 2D 旋转几何图解】
将特征维度两两成对 (x1, x2)，在 2D 平面上旋转角度 m·θ:

      x2 (虚轴)
        ▲        [x1', x2'] = R(mθ) · [x1, x2]
        │          /
        │         / 旋转角度 m·θ
        │        /
        │       /
        │      /
        │     * [x1, x2]
        │    /
        │   /
        └──┼────────────────> x1 (实轴)

相对位置不变性:
<R(mθ) q, R(nθ) k> = q^T · R(mθ)^T · R(nθ) · k = q^T · R((n - m)θ) · k
两个 token 之间的内积只取决于它们的相对距离 (n - m)，完美实现相对位置感知！
```

### 三、核心概念与五要素表

| 五要素 | RoPE 旋转位置编码算子 |
|---|---|
| **输入 (Input)** | 待旋转的查询向量 $Q$ 或键向量 $K \in \mathbb{R}^{B 	imes T 	imes H 	imes d}$，位置索引序列 $m \in [0, T-1]$。 |
| **做什么 (Process)** | 计算基频 $	heta_i = 10000^{-2i/d}$；计算角度 $m 	heta_i$；将特征按相邻对切分；利用复数乘法旋转变换：$[x_1 \cos - x_2 \sin, x_1 \sin + x_2 \cos]$。 |
| **输出 (Output)** | 旋转后的新向量 $	ilde{Q}, 	ilde{K}$。 |
| **哪里出错 (Failure Modes)** | 1. 旋转只施加在 Q 和 K 上，误对 V 也旋转（Value 承载内容信息，绝不能旋转！）；2. 旋转正负号写反。 |
| **参数影响 (Parameters)** | 底数 Base（默认 10000）：调大 Base（如 500,000 或 1,000,000）是实现 128k/1M 超长文本外推的关键技巧。 |

### 四、代码动手实践与严格断言

```python
"""8.7 纯手写 RoPE (Rotary Position Embedding) 算子与相对位置内积断言

纯 NumPy 实现：
1. 预计算旋转角度矩阵 cos 和 sin；
2. 实现纯 NumPy 的 apply_rotary_emb 算子；
3. 严格验证相对位置不变性：位置 (m, n) 的内积与位置 (m+k, n+k) 的内积必须严格相等！
"""
import numpy as np

class RotaryEmbeddingNumpy:
    def __init__(self, dim: int, base: float = 10000.0):
        assert dim % 2 == 0, "RoPE 特征维度必须为偶数！"
        self.dim = dim
        self.base = base
        # 计算不同维度的频率 theta_i: (dim/2,)
        self.inv_freq = 1.0 / (base ** (np.arange(0, dim, 2, dtype=np.float32) / dim))

    def get_rotary_cos_sin(self, seq_len: int) -> tuple[np.ndarray, np.ndarray]:
        t = np.arange(seq_len, dtype=np.float32)  # (seq_len,)
        freqs = np.outer(t, self.inv_freq)       # (seq_len, dim/2)
        # 将频率沿最后一个维度重复拼成完整维度 (seq_len, dim)
        freqs = np.repeat(freqs, 2, axis=-1)
        cos = np.cos(freqs)
        sin = np.sin(freqs)
        return cos, sin

def rotate_half(x: np.ndarray) -> np.ndarray:
    """将向量特征两两一组旋转 90 度: [-x2, x1, -x4, x3, ...]"""
    x_reshaped = x.reshape(*x.shape[:-1], -1, 2)
    x1 = x_reshaped[..., 0]
    x2 = x_reshaped[..., 1]
    rotated = np.stack((-x2, x1), axis=-1).reshape(x.shape)
    return rotated

def apply_rotary_pos_emb(x: np.ndarray, cos: np.ndarray, sin: np.ndarray) -> np.ndarray:
    """RoPE 核心公式: x * cos + rotate_half(x) * sin"""
    return (x * cos) + (rotate_half(x) * sin)

def self_test():
    dim = 8
    seq_len = 10
    rope = RotaryEmbeddingNumpy(dim=dim)
    cos, sin = rope.get_rotary_cos_sin(seq_len)
    
    np.random.seed(42)
    # 构造两个固定的随机单向量
    q = np.random.randn(dim)
    k = np.random.randn(dim)
    
    # 模拟在位置 m=2 处注入 q，在位置 n=5 处注入 k
    # 此时它们的相对距离为 delta = 5 - 2 = 3
    q_pos2 = apply_rotary_pos_emb(q, cos[2], sin[2])
    k_pos5 = apply_rotary_pos_emb(k, cos[5], sin[5])
    dot_product_1 = np.dot(q_pos2, k_pos5)
    
    # 现在将两个 token 同时平移 3 个位置：m=5, n=8
    # 相对距离依然为 delta = 8 - 5 = 3
    q_pos5 = apply_rotary_pos_emb(q, cos[5], sin[5])
    k_pos8 = apply_rotary_pos_emb(k, cos[8], sin[8])
    dot_product_2 = np.dot(q_pos5, k_pos8)
    
    print(f"8.7 自检: 位置 (2,5) 内积 = {dot_product_1:.6f}, 位置 (5,8) 内积 = {dot_product_2:.6f}")
    # 核心数学不变量断言：RoPE 必须保证相对位置内积严格相等！
    assert np.isclose(dot_product_1, dot_product_2, atol=1e-5), "RoPE 相对位置不变性断言失败！"
    print("✅ 8.7 RoPE 旋转位置编码相对位置不变性自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：RoPE 为什么只作用在 Q 和 K 上，而不作用在 V 上？
  - **白板口述框架**：
    1. **Q 和 K 负责计算“相对距离”**：注意力的几何权重是由 $Q K^T$ 决定的。把位置信息通过旋转注入 $Q$ 和 $K$，是为了让它们的内积自动携带 $\Delta = n - m$ 的相对距离衰减信息。
    2. **V 负责承载“客观真实内容”**：$V$ 存储的是具体的语义信息。如果对 $V$ 也进行空间旋转，相当于把内容本身在几何上给扭曲了，破坏了加权求和后真实特征的无偏性。
