### 一、提出问题与真实痛点

在很多转行与校招面试中，候选人一提到 Transformer 就背诵“输入经过编码器和注意力”，但只要面试官追问一句：
- “请在白板上写出从用户输入字符串，到最终输出下一个词的每一步**张量形状（Tensor Shape）**变换，包括输入层、中间隐藏层、LM Head、直到 Logits 和 Softmax 的全生命周期”，大部分人当场卡壳在维度配平上。
- **真实生产痛点**：张量维度错配是所有模型训练和部署阶段最隐蔽、最容易崩溃的 Bug。只有在脑海中对 `(B, T)`、`(B, T, C)`、`(B, T, Vocab)` 建立起毫厘不爽的几何肌肉记忆，才能在手撕代码和模型排障中做到心中有数。

---

### 概念主线：前面的问题如何解决

**一句话：** 文本经过 tokenizer 变成 token ID；Embedding 表把每个 ID 映射到 C 维向量；模型还需要位置信息，然后进入多层 Block。

### 二、心智模型与 ASCII 图解

```
【Transformer 端到端数据流与张量形状追踪】
输入文本: "我爱代码" ──Tokenizer──> Token IDs: [201, 514, 882, 910]  (形状: [B, T])
                                              │
                                              ▼
                    Embedding 查表 + 位置编码 (形状: [B, T, C])
                                              │
                                              ▼
               ┌──────────────────────────────────────────────┐
               │  Transformer Block 1 ~ N (形状保持: [B, T, C]) │
               │  [LayerNorm] ──> [Attention] ──> [Residual]  │
               │  [LayerNorm] ──> [FeedForward] ──> [Residual]│
               └──────────────────────────────────────────────┘
                                              │
                                              ▼
                     最终 LayerNorm 隐藏态 (形状: [B, T, C])
                                              │
                                              ▼
               LM Head 线性投影 (W_lm: [C, Vocab_Size])
                                              │
                                              ▼
                     输出 Logits 矩阵 (形状: [B, T, Vocab_Size])
                                              │
                                              ▼
                     Softmax 概率分布 ──> 采样下一个 Token ID!
```

---

### 三、核心概念与五要素表

| 五要素 | Transformer 数据流全链路 |
|---|---|
| **输入 (Input)** | 批次文本 Token IDs `[B, T]`，词表大小 `V`，隐藏维度 `C`。 |
| **做什么 (Process)** | 查表映射为密集向量 `[B, T, C]`；流经 $N$ 层堆叠 Block；最后一层归一化后经 LM Head 矩阵乘映射回词表空间。 |
| **输出 (Output)** | 未归一化概率得分 Logits `[B, T, V]`。 |
| **哪里出错 (Failure Modes)** | 1. LM Head 权重与 Embedding 权重转置方向写反；2. 混淆 Logits（实数得分）与 Softmax Probabilities（概率和为 1）。 |
| **参数影响 (Parameters)** | 词表大小 $V$ 直接决定 LM Head 的显存与计算开销；Weight Tying（权重绑定）技术可将两者参数共享，节省显存。 |

### 四、代码动手实践与严格断言

```python
"""8.3 端到端张量形状流转与 LM Head 映射校验器

纯 NumPy 实现：
1. Token ID 查表 (B, T) -> (B, T, C)；
2. 模拟 N 层 Transformer Block 隐藏态形状恒等不变性；
3. LM Head 投影映射为 Logits (B, T, V)；
4. Softmax 概率分布归一化；
5. 严格验证全流程维度与概率和为 1.0 断言。
"""
import numpy as np

def simulate_transformer_pipeline(
    token_ids: np.ndarray,
    vocab_size: int = 50,
    channels: int = 16,
    num_layers: int = 2,
    seed: int = 42
) -> tuple[np.ndarray, np.ndarray]:
    np.random.seed(seed)
    B, T = token_ids.shape
    
    # 1. Token Embedding 表: (vocab_size, channels)
    embedding_table = np.random.randn(vocab_size, channels) * 0.02
    
    # 查表得到初始隐藏态: (B, T, C)
    hidden_states = embedding_table[token_ids]
    assert hidden_states.shape == (B, T, channels), f"Embedding 形状异常: {hidden_states.shape}"
    
    # 2. 经过 num_layers 层 Transformer Blocks
    # 核心几何不变量：每一层 Block 的输入与输出形状必须严格恒等于 (B, T, C)！
    for layer_idx in range(num_layers):
        # 模拟注意力与 FFN 残差更新
        residual = hidden_states
        update = np.random.randn(B, T, channels) * 0.01
        hidden_states = residual + update
        assert hidden_states.shape == (B, T, channels), f"Layer {layer_idx} 形状破坏！"
        
    # 3. LM Head 投影矩阵: (channels, vocab_size)
    lm_head_weight = np.random.randn(channels, vocab_size) * 0.02
    
    # 矩阵乘法: (B, T, C) @ (C, V) -> (B, T, V)
    logits = np.matmul(hidden_states, lm_head_weight)
    assert logits.shape == (B, T, vocab_size), f"Logits 形状异常: {logits.shape}"
    
    # 4. Softmax 计算概率分布
    # 数值稳定性：减去行最大值
    max_logits = np.max(logits, axis=-1, keepdims=True)
    exp_logits = np.exp(logits - max_logits)
    probs = exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)
    
    return logits, probs

def self_test():
    B, T = 2, 4
    vocab_size = 30
    channels = 8
    
    # 构造随机 Token ID 批次
    mock_input_ids = np.random.randint(0, vocab_size, size=(B, T))
    logits, probs = simulate_transformer_pipeline(mock_input_ids, vocab_size, channels)
    
    # 断言形状
    assert logits.shape == (B, T, vocab_size)
    assert probs.shape == (B, T, vocab_size)
    
    # 严格断言每个位置预测下一个词的概率和必须为 1.0 (容许 1e-6 浮点误差)
    prob_sums = np.sum(probs, axis=-1)
    assert np.allclose(prob_sums, 1.0, atol=1e-5), "Softmax 归一化概率和不等于 1！"
    
    print(f"8.3 自检通过: Logits 形状 = {logits.shape}, 概率和验证全部合规！")
    print("✅ 8.3 端到端数据流从 Token 到 Logits 自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：大模型生成文本时，是拿最后一个 Token 的 Logits 还是整条序列的 Logits 做采样？
  - **白板口述框架**：
    1. **训练阶段（并行全序列）**：输入整条长度为 $T$ 的序列，模型输出整个 $(B, T, V)$ 的 Logits 矩阵；通过移位操作（Shifted），每个位置 $t$ 的 Logits 负责预测位置 $t+1$ 的真实 Token，整条序列并行计算交叉熵损失。
    2. **推理生成阶段（只取最后一个位置）**：在自回归解码中，我们只需要知道模型对“未来下一个词”的预测分布，因此直接提取最后一个位置 $t=T$ 对应的 Logits 向量 $(B, 1, V)$；经过温度系数调节和 top-p/top-k 采样，采出第 $T+1$ 个 Token 追加回序列。
