### 一、提出问题与真实痛点

在很多深度学习架构面试中，面试官让候选人在白板上写出单个 Transformer Block（层）的完整计算流水线。
- **经典踩坑点**：
  1. 忘记把输入拆分为两条分支（残差直通分支 + 变换分支）；
  2. 把 LayerNorm 的位置放错（误写成 Post-LN 导致深层梯度弥散）；
  3. 忘记 FFN 层的通道升采样比例（标准规范是 $C 	o 4C 	o C$ 或 SwiGLU 的 $ rac{8}{3}C$）；
  4. 形状没有保持恒等闭环，导致无法无限层无缝堆叠。
- **设计哲学**：
  一个合规的 Transformer Block 必须是一个**黑盒形状恒等算子**：无论输入什么隐藏特征 $(B, T, C)$，流经内部注意力与 FFN 两道残差关卡后，输出必须依然是毫厘不差的 $(B, T, C)$！

---

### 概念主线：前面的问题如何解决

**一句话：** 注意力在位置间交换信息；FFN 对每个位置的通道做非线性变换；残差保留输入通路；LayerNorm 稳定特征尺度。

### 三、核心概念与五要素表

| 五要素 | 单层 Transformer Block 核心组件 |
|---|---|
| **输入 (Input)** | 隐藏特征张量 $X \in \mathbb{R}^{B 	imes T 	imes C}$。 |
| **做什么 (Process)** | 第 1 关（注意力）：$	ext{Norm} 	o 	ext{MHA} 	o 	ext{残差加和}$；第 2 关（前馈网络）：$	ext{Norm} 	o 	ext{FFN} 	o 	ext{残差加和}$。 |
| **输出 (Output)** | 更新后的隐藏特征张量 $	ilde{X} \in \mathbb{R}^{B 	imes T 	imes C}$。 |
| **哪里出错 (Failure Modes)** | 1. 两次残差分支没有把原始特征与子层变换严格相加；2. 隐藏维度在 FFN 升维后没有成功降回 $C$。 |
| **参数影响 (Parameters)** | 单层 Block 的参数量大约占总模型除以层数的份额，是评估模型总参数（如 7B/14B）的核心基元。 |

### 四、代码动手实践与严格断言

```python
"""8.9 纯手写完整 Pre-LN Transformer Block 架构

纯 NumPy 实现：
1. 包含 RMSNorm、MultiHeadAttention、两层 FFN；
2. 严格遵循 Pre-LN 两阶段残差连接结构；
3. 深度验证输入输出形状完全一致断言与多层串联。
"""
import numpy as np

class PureNumpyRMSNorm:
    def __init__(self, dim: int, eps: float = 1e-6):
        self.eps = eps
        self.gamma = np.ones(dim, dtype=np.float32)

    def forward(self, x: np.ndarray) -> np.ndarray:
        rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + self.eps)
        return (x / rms) * self.gamma

class PureNumpyTransformerBlock:
    def __init__(self, channels: int = 16, num_heads: int = 4, mlp_ratio: int = 4, seed: int = 42):
        self.channels = channels
        self.num_heads = num_heads
        self.d_k = channels // num_heads
        
        np.random.seed(seed)
        # 归一化层
        self.norm1 = PureNumpyRMSNorm(channels)
        self.norm2 = PureNumpyRMSNorm(channels)
        
        # MHA 投影
        self.W_q = np.random.randn(channels, channels) * 0.05
        self.W_k = np.random.randn(channels, channels) * 0.05
        self.W_v = np.random.randn(channels, channels) * 0.05
        self.W_o = np.random.randn(channels, channels) * 0.05
        
        # FFN 两层投影: C -> 4C -> C
        hidden_dim = channels * mlp_ratio
        self.W_gate = np.random.randn(channels, hidden_dim) * 0.05
        self.W_down = np.random.randn(hidden_dim, channels) * 0.05

    def _mha(self, x: np.ndarray, is_causal: bool = True) -> np.ndarray:
        B, T, C = x.shape
        Q = np.matmul(x, self.W_q).reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        K = np.matmul(x, self.W_k).reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        V = np.matmul(x, self.W_v).reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        
        scores = np.matmul(Q, K.swapaxes(-1, -2)) / np.sqrt(self.d_k)
        if is_causal:
            mask = np.triu(np.ones((T, T), dtype=np.float32), k=1) * -1e9
            scores += mask
            
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        attn_out = np.matmul(weights, V).swapaxes(1, 2).reshape(B, T, C)
        return np.matmul(attn_out, self.W_o)

    def _ffn(self, x: np.ndarray) -> np.ndarray:
        # 简单两层 ReLU FFN
        h = np.maximum(0.0, np.matmul(x, self.W_gate))
        out = np.matmul(h, self.W_down)
        return out

    def forward(self, x: np.ndarray, is_causal: bool = True) -> np.ndarray:
        # 第 1 道关卡：Pre-LN -> MHA -> 残差
        h1 = x + self._mha(self.norm1.forward(x), is_causal=is_causal)
        # 第 2 道关卡：Pre-LN -> FFN -> 残差
        out = h1 + self._ffn(self.norm2.forward(h1))
        return out

def self_test():
    B, T, C = 2, 6, 16
    np.random.seed(42)
    x = np.random.randn(B, T, C)
    
    # 构建 3 层堆叠
    block1 = PureNumpyTransformerBlock(channels=C, num_heads=4, seed=1)
    block2 = PureNumpyTransformerBlock(channels=C, num_heads=4, seed=2)
    block3 = PureNumpyTransformerBlock(channels=C, num_heads=4, seed=3)
    
    h1 = block1.forward(x)
    assert h1.shape == (B, T, C)
    
    h2 = block2.forward(h1)
    assert h2.shape == (B, T, C)
    
    h3 = block3.forward(h2)
    assert h3.shape == (B, T, C)
    print("✅ 8.9 纯手写 Pre-LN Transformer Block 多层级联自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：请手算一个标准 7B 模型的单个 Transformer Block 包含多少参数量？
  - **白板口述框架**：
    以 LLaMA-7B 为例：隐藏维度 $C=4096$，FFN 中间隐藏维通常取 $11008$（使用 SwiGLU 三个矩阵）：
    1. **自注意力部分**：
       - $W_q, W_k, W_v, W_o$ 四个矩阵，每个尺寸为 $4096 	imes 4096  pprox 16.78	ext{M}$ 参数。
       - MHA 合计参数量：$4 	imes 16.78	ext{M}  pprox 67.1	ext{M}$。
    2. **FFN 部分（SwiGLU 架构）**：
       - 包含 $W_{	ext{gate}}, W_{	ext{up}}, W_{	ext{down}}$ 三个矩阵。
       - 每个矩阵尺寸为 $4096 	imes 11008  pprox 45.09	ext{M}$ 参数。
       - FFN 合计参数量：$3 	imes 45.09	ext{M}  pprox 135.3	ext{M}$。
    3. **单层总计**：
       - $67.1	ext{M} + 135.3	ext{M}  pprox 202.4	ext{M}$ 参数。
    4. **全模型堆叠**：
       - 7B 模型堆叠 32 层：$32 	imes 202.4	ext{M}  pprox 6.48	ext{B}$。
       - 加上 Embedding 表和输出 Head（$32000 	imes 4096  pprox 131	ext{M}$），正好构成标准的 6.7B~7.0B 总参数量！
