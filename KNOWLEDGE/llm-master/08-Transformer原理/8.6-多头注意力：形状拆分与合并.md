### 一、提出问题与真实痛点

“既然单头注意力已经能计算全序列交互，为什么还要大费周章搞 **多头注意力 (Multi-Head Attention, MHA)**？”
- **单头注意力的局限（单一子空间的注意力瓶颈）**：
  单头注意力在一个高维空间计算权重，只能得出一个全局综合分数。但在实际语言中，一个词在句法上可能同时承担多种角色！
  例如句子：“**小明** 在操场上 飞快地 踢了 **足球**。”
  - 角色 1（主谓关系）：关注动作“踢”；
  - 角色 2（空间方位）：关注地点“操场”；
  - 角色 3（修饰副词）：关注状态“飞快地”；
  - 角色 4（动宾对象）：关注目标“足球”。
  如果只有一个头，所有关注点互相撕扯抵消；而通过多头机制，将特征维度切分成 $H$ 个独立的子空间，**头 1 专门关注主谓、头 2 专门关注地点、头 3 专门关注修饰语**，从而在多个不同表示子空间并行捕捉多重语义依赖！

---

### 概念主线：前面的问题如何解决

**一句话：** 把隐藏维分给多个头，每个头做自己的 Q/K/V 注意力，再拼接并映射回隐藏维；多头增加可学习的表示路径，但不能保证每个头天然承担固定语法角色。

### 二、心智模型与 ASCII 图解

```
【多头注意力：拆头、独立子空间与拼接合并】
 输入 X: (B, T, C)
     │
     ├── W_q (C, C) ──> Q: (B, T, C) ──Reshape/Transpose──> (B, H, T, d_k)
     ├── W_k (C, C) ──> K: (B, T, C) ──Reshape/Transpose──> (B, H, T, d_k)
     └── W_v (C, C) ──> V: (B, T, C) ──Reshape/Transpose──> (B, H, T, d_v)
                                                                 │
                                ┌────────────────────────────────┘
                                ▼ 每个头在独立子空间并行算 Attention
                  Head 1: (B, T, d_v)  Head 2: (B, T, d_v) ... Head H: (B, T, d_v)
                                │               │                     │
                                └───────────────┼─────────────────────┘
                                                ▼ 沿特征维度拼接 (Concat)
                                      MultiHead_Out: (B, T, H * d_v) = (B, T, C)
                                                │
                                                ▼ 线性投影 W_o (C, C)
                                          Final_Output: (B, T, C)
```

### 三、核心概念与五要素表

| 五要素 | 多头注意力 (MHA) 核心机制 |
|---|---|
| **输入 (Input)** | 输入张量 $X \in \mathbb{R}^{B 	imes T 	imes C}$，头数 $H$，每个头的维度 $d_k = C / H$。 |
| **做什么 (Process)** | 拆头：通过 `view` 和 `transpose` 将张量重排为 `(B, H, T, d_k)`；各头独立计算 Scaled Dot-Product Attention；拼接：通过 `transpose` 和 `contiguous().view` 合并为 `(B, T, C)`；经过输出投影矩阵 $W_o$。 |
| **输出 (Output)** | 多头聚合上下文张量 `[B, T, C]`。 |
| **哪里出错 (Failure Modes)** | 1. 拆头维度整除性错误（$C \% H 
eq 0$）；2. 混淆 `(B, H, T, d)` 与 `(B, T, H, d)` 导致注意力跨序列错乱。 |
| **参数影响 (Parameters)** | 头数 $H$ 决定并行语义子空间数量；总计算量与单头全量计算完全一致，多头并没有增加浮点运算量！ |

### 四、代码动手实践与严格断言

```python
"""8.6 纯手写多头注意力形状拆分与拼接算子

纯 NumPy 实现：
1. 投影 Q, K, V 并拆解为 (B, H, T, d_k)；
2. 批量多维矩阵乘法计算各头独立的注意力分布；
3. 纯手写还原合并拼接为 (B, T, C)；
4. 经过输出投影层 W_o；
5. 严格形状断言与单头对比。
"""
import numpy as np

class PureNumpyMultiHeadAttention:
    def __init__(self, channels: int = 16, num_heads: int = 4, seed: int = 42):
        assert channels % num_heads == 0, "通道数必须能被头数整除！"
        self.channels = channels
        self.num_heads = num_heads
        self.d_k = channels // num_heads
        
        np.random.seed(seed)
        self.W_q = np.random.randn(channels, channels) * 0.05
        self.W_k = np.random.randn(channels, channels) * 0.05
        self.W_v = np.random.randn(channels, channels) * 0.05
        self.W_o = np.random.randn(channels, channels) * 0.05

    def forward(self, X: np.ndarray, is_causal: bool = True) -> np.ndarray:
        B, T, C = X.shape
        
        # 1. 线性投影: (B, T, C) @ (C, C) -> (B, T, C)
        Q = np.matmul(X, self.W_q)
        K = np.matmul(X, self.W_k)
        V = np.matmul(X, self.W_v)
        
        # 2. 核心形状重排：(B, T, H, d_k) -> (B, H, T, d_k)
        Q = Q.reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        K = K.reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        V = V.reshape(B, T, self.num_heads, self.d_k).swapaxes(1, 2)
        
        # 3. 批量注意力分数: (B, H, T, d_k) @ (B, H, d_k, T) -> (B, H, T, T)
        scores = np.matmul(Q, K.swapaxes(-1, -2)) / np.sqrt(self.d_k)
        
        if is_causal:
            mask = np.triu(np.ones((T, T), dtype=np.float32), k=1) * -1e9
            scores = scores + mask
            
        # 4. Softmax
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        
        # 5. 加权上下文: (B, H, T, T) @ (B, H, T, d_k) -> (B, H, T, d_k)
        attn_out = np.matmul(weights, V)
        
        # 6. 还原与拼接：(B, H, T, d_k) -> (B, T, H, d_k) -> (B, T, C)
        concat_out = attn_out.swapaxes(1, 2).reshape(B, T, C)
        
        # 7. 输出投影
        final_out = np.matmul(concat_out, self.W_o)
        return final_out

def self_test():
    B, T, C, H = 2, 4, 16, 4
    np.random.seed(42)
    X = np.random.randn(B, T, C)
    
    mha = PureNumpyMultiHeadAttention(channels=C, num_heads=H)
    out = mha.forward(X, is_causal=True)
    
    # 核心不变量断言：多头注意力输出形状必须与输入 X 完全一致！
    assert out.shape == (B, T, C), f"形状不一致: {out.shape} vs {X.shape}"
    print("✅ 8.6 纯手写多头注意力拆头与拼接自检全部通过！")

if __name__ == '__main__':
    self_test()
```

### 五、面试通关口述与避坑

- **高频追问**：多头注意力会增加模型的参数量和计算量吗？
  - **白板口述框架**：
    1. **参数量完全不变**：设输入输出维度为 $C$。如果是单头，投影矩阵为 $C 	imes C$；如果是 $H$ 个头，每个头维度为 $d_k = C/H$，每个头的投影矩阵为 $C 	imes (C/H)$，全部 $H$ 个头并起来依然是 $C 	imes C$。输出矩阵 $W_o$ 同样是 $C 	imes C$。因此参数量与单头完全相等！
    2. **计算量 (FLOPs) 完全不变**：矩阵乘法的计算复杂度取决于维度总乘积。无论是单头一次算 $(B, T, C) 	imes (B, C, T)$，还是 $H$ 个头并发算 $H 	imes (B, T, C/H) 	imes (B, C/H, T)$，总运算次数严格相等。多头的真正红利是用相同的算力，换取了多表示子空间的丰富语义表达能力。
