### 8.9 Transformer Block：串联多头与 FFN 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：单个零件（MHA、FFN、RMSNorm、Residual）都看懂了，但面试官让你画一个完整 Pre-LN Transformer Block 的数据流图时，最容易把“Norm 放残差里面还是外面”画反！

本节解法：锁定标准 Pre-LN Block 拓扑：h = x + MHA(Norm1(x)) -> out = h + FFN(Norm2(h))，实现输入 (B, T, C) 与输出 (B, T, C) 严格等维，方便任意堆叠 $L$ 层！

大白话例子：就像一条标准化的汽车总装流水线：每一节车间（Block）的入口门框和出口门框尺寸完全一样 (B, T, C)，车架沿着主传送带（残差流）一直往前走，1 号机械臂（MHA）和 2 号机械臂（FFN）各自先做一次标准化校准（Norm）再把加工增量焊回主车架上！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 隐藏状态 x: (B, T, C)。 |
| ② 做什么 | Pre-LN 双残差流转：先 Norm 后 Attention 加回 x -> 再 Norm 后 FFN 加回 h。 |
| ③ 输出什么 | 同形状输出 (B, T, C)，确保任意堆叠 $N$ 层无维度断点。 |
| ④ 关键参数 | d_model ($C$)、残差流方差稳定度。 |
| ⑤ 工程 Trade-off | 标准化等维 Block 让模型可以靠堆叠深度（$12 \to 32 \to 80$ 层）直接吃满 Scaling Law，且方便做张量并行（TP）与流水线并行（PP）切分。 |

#### 3. 💻 渐进式代码实操（Step 9：Pre-LN Block 残差流追踪）

演进说明：验证标准 Pre-LN Block 内部特征方差与形状不变性（完整类实现见 9.5 节）。

```python
"""8.9 Step 9: 单个 Pre-LN Block 的残差流形状与幅值稳定性追踪."""

from __future__ import annotations

import numpy as np


def rms_norm(x: np.ndarray, eps: float = 1e-6) -> np.ndarray:
    return x / np.sqrt(np.mean(x * x, axis=-1, keepdims=True) + eps)  # [必背手撕-RMSNorm核心] 仅用均方根缩放且 eps 在根号内防除零


def trace_pre_ln_block(x: np.ndarray) -> dict[str, object]:
    norm1 = rms_norm(x)  # [必记设计决策-Pre-LN位置] 归一化置于子层输入前，保留主干残差通路无阻
    h = x + norm1 * 0.1  # [必背手撕-注意力残差] 第一条残差分支汇合
    norm2 = rms_norm(h)
    out = h + norm2 * 0.1  # [必背手撕-FFN残差] 第二条残差分支汇合，保持 (B, T, C) 形状不变
    assert out.shape == x.shape
    return {"input_std": round(float(np.std(x)), 4), "output_std": round(float(np.std(out)), 4)}


if __name__ == "__main__":  # [无需死背-脚手架] 自测入口
    x = np.random.default_rng(3).normal(size=(2, 8, 32))
    res = trace_pre_ln_block(x)
    assert 0.8 < res["output_std"] < 1.3
    print(f"Ch8 Step 9 self-test passed! res={res}")
```

### 🧠 代码区记忆清单：背什么 vs 不背什么

🔒 不可替代的系统设计决策：现代大模型采用 Pre-LN（x + Sublayer(Norm(x))）取代 Post-LN，确保残差主干不被 Norm 打断，训练无需繁琐 Warmup 即可稳定收敛。

✍️ 面试手撕/默写范围：rms_norm(x) 核心公式与 Pre-LN 双残差流数据路径。

🗑️ 无需死背的脚手架代码：统计字典 input_std / output_std 打包与 __main__ 断言。

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：Block 输入与输出形状恒为 (B, T, C)；x 本身直接无损流向输出端，任何子层都只贡献增量。

讲清关键行：注意 h = x + sublayer(norm(x)) 中，加回的是未归一化的原始 x，而不是 norm(x)！这是 Pre-LN 的核心。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：写代码时手滑写成 h = norm(x) + sublayer(norm(x))

现象：深层残差高速公路被切断，每一层都在强行重置信号尺度，深层训练效果大幅退化。

定位方法：核对残差加法左侧是否为原始 x。

修复方案：改为 x + sublayer(norm(x))。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么说 Pre-LN 的最后一层 Block 出来之后，进入 lm_head 之前还要额外加一个 final_norm？

参考答法：因为在 Pre-LN 中，每个子层的输入被 Norm 过了，但残差主路一路累加下来到最后一层输出时并没有被 Norm 过（方差可能较大），所以送进 lm_head 算 Logits 前必须加一个 final_norm 统一尺度。
