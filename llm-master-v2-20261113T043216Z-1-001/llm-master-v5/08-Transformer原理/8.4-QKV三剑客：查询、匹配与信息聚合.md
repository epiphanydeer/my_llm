### 8.4 QKV 三剑客：查询、匹配与信息聚合 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：既然都是同一个输入序列 X，为什么不直接用 X @ X.T 算词与词的相似度，非要大费周章乘三个独立矩阵 $W_Q, W_K, W_V$ 拆出 Query、Key、Value？

本节解法：用信息检索视角解耦“我在找什么（$Q$）”、“我有什么特征供别人检索（$K$）”和“如果被选中我要贡献什么内容（$V$）”，并从数学上验证独立 $W_Q, W_K$ 打破了对称性，让“我关注你”和“你关注我”可以拥有完全不同的权重！

大白话例子：就像在 B 站搜视频：Query 是你在搜索框输入的“手写 Transformer 教程”；Key 是每个视频的标题和标签；Value 是视频真正的播放内容。系统用你的 Query 去和所有视频的 Key 做匹配打分，再按匹配度加权把对应的 Value（视频内容）聚合给你！如果不用三个独立矩阵，就相当于强制要求“搜索词、视频标题、视频正文必须一模一样”，显然荒谬！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 隐藏状态 x: (T, d) 与独立投影矩阵 W_Q, W_K, W_V。 |
| ② 做什么 | 对比无投影对称打分 x @ x.T 与独立线性投影后的非对称打分 (x @ W_Q) @ (x @ W_K).T。 |
| ③ 输出什么 | 验证矩阵对称性被打破的布尔断言。 |
| ④ 关键参数 | W_Q, W_K, W_V 各自映射出不同子空间。 |
| ⑤ 工程 Trade-off | 独立投影增加 3 倍投影参数量，但赋予了模型非对称句法指向能力（例如代词“它”高度关注前文“苹果”，而“苹果”并不需要反过来同等关注“它”）。 |

#### 3. 💻 渐进式代码实操（Step 4：验证独立 Q/K 打破对称性）

演进说明：用 15 行代码直观证明引入 $W_Q, W_K$ 后注意力打分矩阵的非对称特性。

```python
"""8.4 Step 4: 验证独立 W_Q / W_K 打破对称性，实现非对称词间检索."""

from __future__ import annotations

import numpy as np


def verify_qkv_asymmetry(x: np.ndarray) -> bool:
    rng = np.random.default_rng(1)  # 脚手架。随机数与测试矩阵初始化
    d = x.shape[-1]
    wq = rng.normal(size=(d, d))
    wk = rng.normal(size=(d, d))
    sym_scores = x @ x.T  # 对称缺陷。直接 x @ x.T 必然对称，无法区分主语找谓语与谓语找主语
    asym_scores = (x @ wq) @ (x @ wk).T  # 非对称投影。独立 W_Q / W_K 线性投影打破对称性，实现有向检索
    assert np.allclose(sym_scores, sym_scores.T)  # 脚手架。对称性对比断言
    assert not np.allclose(asym_scores, asym_scores.T)
    return True


if __name__ == "__main__":  # 脚手架。自测入口
    x = np.random.default_rng(2).normal(size=(4, 8))
    assert verify_qkv_asymmetry(x) is True
    print("Ch8 Step 4 self-test passed!")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：X @ X.T 永远是对称矩阵（且对角线自匹配分数往往最大），无法表达单向指向关系；引入独立 $W_Q, W_K$ 后打分矩阵不再对称。

讲清关键行：asym_scores 把“发出查询的视角”和“被检索索引的视角”彻底解耦。

主动点出工程细节：为了提升 GPU 计算密度，生产代码（如 Megatron / nanoGPT）常把三个线性层合并成一次 c_attn = nn.Linear(C, 3 * C) 矩阵乘。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：融合 c_attn 拆分时写错维度，导致 Q/K/V 混在一起

现象：模型训练不收敛，输出乱码。

定位方法：检查 q, k, v = qkv.split(C, dim=-1) 的 dim 参数以及权重加载时的切片顺序。

修复方案：严格在最后一维 -1 切分，并加形状断言。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么 Self-Attention 里不能省掉 $W_Q, W_K, W_V$ 直接用 $X X^T X$？

参考答法：① $X X^T$ 强迫矩阵对称，导致“词 A 对词 B 的关注度”必须等于“词 B 对词 A 的关注度”，违背自然语言单向修饰规律；② 对角线 $x_i \cdot x_i$ 极大，会导致每个词几乎只关注自己、学不到跨词聚合。

## 面试重点｜设计、调参与排障

**面试官可能问**

Q、K、V 为什么分别投影？Q=K 时哪个矩阵对称？

**参考回答（现场口述）**

Q 描述当前 token 需要找什么，K 描述候选怎么被匹配，V 提供匹配后聚合的内容。在同一序列 Q=K 时，掩码和 softmax 前的 QK 转置所得 Gram 分数对称。逐行归一化或加因果掩码后一般不对称。

**系统设计怎么选**

Q/K 提供匹配表示，V 携带聚合内容。Q=K 时未掩码的 QK 转置点积分数对称，逐行 softmax 后不保证对称，掩码也会改变可见性。

**参数或条件改变会怎样**

改变头宽或投影布局会改变形状和容量，先写各矩阵的输入输出轴再谈参数与代价。

**系统出错怎么查、怎么验证**

构造一个两行 logits，分母不同即可解释权重为何不对称。用指定输入验算分数与输出。
