### 8.5 Attention 计算：点积、缩放与 Mask 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：算出 $Q K^T$ 之后，为什么要多此一举除以 $\sqrt{d_k}$？直接丢进 Softmax 不行吗？而且掩码时为什么必须填 -inf（或 -1e9）而不是填 0？

本节解法：从概率论方差推导 $\sqrt{d_k}$ 缩放原理：当 $q, k$ 各分量独立同分布均值为 0、方差为 1 时，点积 $\sum_{i=1}^{d_k} q_i k_i$ 的方差高达 $d_k$！除以 $\sqrt{d_k}$ 才能把方差拉回 1，防止 Softmax 落入饱和区导致梯度消失；并明确掩码必须加在 Softmax 之前（填 $-\infty$ 使 $e^{-\infty}=0$）。

大白话例子：1000 个人打分如果直接把分数加起来，总分可能动辄飙到 +500 和 -500，一进 Softmax 就变成 [1.0, 0.0, 0.0...] 极端独裁（坡度全平，反向传播梯度全为 0）；除以 $\sqrt{d_k}$ 相当于把总分拉回正常百分制，让大家都能柔和地分配注意力并顺利传回梯度！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 独立标准正态分布样本 q, k: (n_samples, d_k)。 |
| ② 做什么 | 对比未缩放点积 sum(q * k) 与缩放点积 sum(q * k) / sqrt(d_k) 的统计方差。 |
| ③ 输出什么 | 方差对比结果：raw_var ≈ d_k vs scaled_var ≈ 1.0。 |
| ④ 关键参数 | d_k（单头维度，常见 64 或 128）。 |
| ⑤ 工程 Trade-off | 缩放几乎零算力成本（可提前融进 $Q$ 或常数乘法），却保住了深层 Transformer 的梯度健康流动。 |

#### 3. 💻 渐进式代码实操（Step 5：数值验证 $\sqrt{d_k}$ 方差归 1）

演进说明：用 15 行 NumPy 数值实验直接证实 $d_k=256$ 时方差从 256 被拉回 1.0。

```python
"""8.5 Step 5: 数值验证为什么点积注意力必须除以 sqrt(d_k) (方差从 d_k 归 1 防梯度消失)."""

from __future__ import annotations

import math
import numpy as np


def verify_scaling_variance(d_k: int = 256, n_samples: int = 2000) -> dict[str, float]:
    rng = np.random.default_rng(42)  # 脚手架。采样实验初始化
    q = rng.normal(0.0, 1.0, size=(n_samples, d_k))
    k = rng.normal(0.0, 1.0, size=(n_samples, d_k))
    raw_dots = np.sum(q * k, axis=-1)  # 方差膨胀。独立标准正态点积和的方差等于维度 d_k
    scaled_dots = raw_dots / math.sqrt(d_k)  # 缩放因子。除以 sqrt(d_k) 将方差拉回 1.0，防止 Softmax 饱和梯度消失
    return {
        "raw_var": round(float(np.var(raw_dots)), 2),
        "scaled_var": round(float(np.var(scaled_dots)), 2),
    }


if __name__ == "__main__":  # 脚手架。自测入口与方差断言
    stats = verify_scaling_variance(256)
    assert stats["raw_var"] > 200.0 and 0.8 < stats["scaled_var"] < 1.2
    print(f"Ch8 Step 5 self-test passed! stats={stats}")
```

### 示例说明与练习范围

本例的设计选择：点积方差随 $d_k$ 线性膨胀，必须除以 $\sqrt{d_k}$ 维持单位方差，避免 Softmax 进入梯度极小的饱和区。

**代码练习｜能讲清设计**。解释推导即可，编码合并到 9.1。

示例辅助代码：n_samples=2000 蒙特卡洛采样、round 统计字典封装与 __main__ 断言。

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：若 $q_i, k_i \sim \mathcal{N}(0, 1)$ 独立，则 $\text{Var}(\sum_{i=1}^{d_k} q_i k_i) = d_k$，除以 $\sqrt{d_k}$ 后标准差和方差精确回归 1。

讲清关键行：若不缩放，当 $d_k=128$ 或 $256$ 时，打分标准差高达 11~16，Softmax 输出瞬间塌缩成近似 One-hot 分布，雅可比矩阵 $\text{diag}(p) - pp^T \approx 0$ 造成梯度消失。

主动点出工程细节：Mask 时必须在 Softmax 之前填 $-\infty$（或 -1e9），千万不能填 0——因为 $e^0 = 1$，填 0 反而会给被屏蔽的未来词分配不小的注意力权重！

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：BF16/FP16 下用 -1e9 做掩码时，偶发溢出或精度异常

现象：FP16 最大正数仅 65504，-1e9 在 FP16 下直接变 -inf 或触发类型转换警告。

定位方法：混精度训练下使用了超出 FP16 表示范围的常数。

修复方案：优先使用 torch.finfo(scores.dtype).min 或原生布尔掩码 masked_fill(mask, float("-inf"))。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么缩放因子是 $\sqrt{d_k}$ 而不是 $d_k$？

参考答法：因为方差随维度线性增长（$\text{Var} = d_k$），标准差随 $\sqrt{d_k}$ 增长；要让方差归 1，只需要除以标准差 $\sqrt{d_k}$。如果除以 $d_k$，方差会缩小成 $1/d_k$ 导致注意力趋于均匀分布、丧失区分度。

## 面试重点｜设计、调参与排障

**面试官可能问**

为什么除以根号 d，Mask 为什么不用 0？

**参考回答（现场口述）**

独立且各维方差为 1 时，d 项点积的方差约为 d，除以根号 d 能控制 logits 尺度。掩码位置填 0，softmax 后仍会有权重，所以用负无穷或等价屏蔽，全遮挡行单独处理。

**系统设计怎么选**

独立、零均值、单位方差假设下，点积方差随 d 增长，缩放抑制 softmax 过度饱和。屏蔽要在归一化前，填 0 仍会分到概率。

**参数或条件改变会怎样**

区分 causal 与 padding，以及 masked 和 allowed 的布尔约定。全屏蔽行需要约定处理。

**系统出错怎么查、怎么验证**

加两个小测试：存在可见项时被屏蔽权重为零；全屏蔽时按约定输出可预测且有限的值。
