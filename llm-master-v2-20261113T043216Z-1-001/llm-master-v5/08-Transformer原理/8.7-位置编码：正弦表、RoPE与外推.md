### 8.7 位置编码：正弦表、RoPE 旋转位置编码与长文本外推 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：Self-Attention 天生是置换不变（Permutation-Invariant）的——如果不给词加位置标记，“我爱你”和“你爱我”在注意力眼里算出来一模一样！早期直接把绝对位置向量加在 Embedding 上（正弦表 / 可学习绝对位置），一旦推理时遇到超过训练长度的文本（比如训 4K 推 32K），位置向量没见过，模型直接崩溃！

本节解法：引入现代大模型绝对主流——RoPE（旋转位置编码，Rotary Position Embedding）：把向量每两维组成复数平面上的点，第 $m$ 个位置的 $Q_m$ 旋转角度 $m\theta$，第 $n$ 个位置的 $K_n$ 旋转角度 $n\theta$；两者点积 $Q_m \cdot K_n$ 经过三角恒等变换后，自然只依赖于相对距离 $(m - n)\theta$！用绝对旋转操作完美实现了相对位置编码！

大白话例子：就像手表指针：12 点（位置 0）和 3 点（位置 3）之间的夹角是 90 度；把两个表盘同时往后拨 10 小时，变成 10 点和 1 点，它们之间的夹角依然还是 90 度（相对距离不变）！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 序列特征 x: (T, D)（$D$ 为偶数）、位置索引 pos: (T,)、旋转基频 base（常见 10000.0，长文本可调大至 500000.0 / 1000000.0）。 |
| ② 做什么 | 计算逆频率 $\theta_i = \text{base}^{-2i/D}$ -> 算角度 $m \theta_i$ -> 对偶数维和奇数维成对施加二维旋转矩阵 [cos, -sin; sin, cos]。 |
| ③ 输出什么 | 注入旋转位置信息后的张量 (T, D)，且满足 $\langle R_m q, R_n k \rangle$ 只取决于 $m - n$。 |
| ④ 关键参数 | base（RoPE 基频，调大 base 减慢低频旋转速度是 NTK-Aware / ABF 长文本外推的核心）。 |
| ⑤ 工程 Trade-off | RoPE 不增加任何可训练参数、天然兼容 KV Cache 与 FlashAttention，并具备良好的长文本外推潜力（NTK/YaRN）。 |

#### 3. 💻 渐进式代码实操（Step 7：手写 RoPE 并验证相对位置不变性）

演进说明：手写核心旋转矩阵变换，并用断言严格证明 (pos=5, pos=2) 与 (pos=15, pos=12) 内积完全相等。

```python
"""8.7 Step 7: 手写 RoPE (旋转位置编码) 并验证内积只依赖相对距离 (m - n)."""

from __future__ import annotations

import numpy as np


def apply_rope(x: np.ndarray, pos: np.ndarray, base: float = 10000.0) -> np.ndarray:
    """x: (T, D), D 为偶数 -> 对每对相邻维度 (2i, 2i+1) 施加角度 m * theta_i 旋转."""
    t, d = x.shape
    assert d % 2 == 0  # [无需死背-脚手架] 偶数维度边界检查
    inv_freq = 1.0 / (base ** (np.arange(0, d, 2, dtype=np.float64) / d))  # [必背手撕-RoPE逆频率] 几何级数衰减频率 theta_i = base^(-2i/d)
    angles = np.outer(pos, inv_freq)  # [必背手撕-外积角度] 位置 m 与频率外积得到旋转角矩阵 (T, d/2)
    cos_a, sin_a = np.cos(angles), np.sin(angles)  # [必记设计决策-绝对转相对] 通过正余弦旋转让 QK 内积只依赖相对距离 (m - n)

    x_even = x[:, 0::2]  # [必背手撕-奇偶配对] 拆分偶维与奇维构成二维复数旋转对
    x_odd = x[:, 1::2]
    out = np.empty_like(x)
    out[:, 0::2] = x_even * cos_a - x_odd * sin_a  # [必背手撕-RoPE旋转实部] x_2i*cos - x_{2i+1}*sin
    out[:, 1::2] = x_even * sin_a + x_odd * cos_a  # [必背手撕-RoPE旋转虚部] x_2i*sin + x_{2i+1}*cos
    return out


if __name__ == "__main__":  # [无需死背-脚手架] 相对位置不变性自测
    rng = np.random.default_rng(7)
    q, k = rng.normal(size=(1, 8)), rng.normal(size=(1, 8))
    dot_1 = float(np.sum(apply_rope(q, np.array([5])) * apply_rope(k, np.array([2]))))
    dot_2 = float(np.sum(apply_rope(q, np.array([15])) * apply_rope(k, np.array([12]))))
    assert np.isclose(dot_1, dot_2, atol=1e-10)
    print(f"Ch8 Step 7 self-test passed! dot_1={dot_1:.6f}, dot_2={dot_2:.6f}")
```

🔒 不可替代的系统设计决策：RoPE 用绝对位置旋转实现相对位置内积（只依赖 $m - n$），且仅作用于 Q/K 而非 V，同时支持调整 base（NTK/YaRN）做长文本外推。

✍️ 面试手撕/默写范围：inv_freq 频率公式、np.outer(pos, inv_freq) 角度矩阵、奇偶维旋转公式（x_even * cos - x_odd * sin 与 x_even * sin + x_odd * cos）。

🗑️ 无需死背的脚手架代码：assert d % 2 == 0、np.empty_like(x) 缓冲区分配与 __main__ 相对距离验证脚本。

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：RoPE 只作用在每一层的 Q 和 K 上（不作用在 V 上），且旋转正交矩阵不改变向量模长；只要 $m - n$ 相同，内积严格相等。

讲清关键行：x_even * cos_a - x_odd * sin_a 与 x_even * sin_a + x_odd * cos_a 就是复数乘法 $(x_e + i x_o) e^{im\theta}$ 的实部与虚部展开。

主动点出工程细节：长文本外推为什么调大 base（如 Qwen/LLaMA-3 从 10000 扩到 1000000）？因为低频维度周期不够长时，遇到超长序列会绕圈撞车；调大 base 相当于把所有频率的波长拉长（NTK 思想），再配合 YaRN 分段插值就能把 4K 模型平滑扩到 128K。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：给模型强行传入超过训练长度 2 倍的文本后，模型开始无限复读乱码

现象：困惑度（PPL）突然飙升。

定位方法：超出了原有 RoPE 基频覆盖的相位范围。

修复方案：启用 YaRN / NTK-RoPE 缩放参数并做少量长文本继续预训练/微调。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：用白板一句话讲清 RoPE 为什么能用绝对位置操作实现相对位置编码？

参考答法：给 $q_m$ 旋转 $m\theta$、给 $k_n$ 旋转 $n\theta$ 后，计算内积 $q_m^T k_n = q^T R_m^T R_n k = q^T R_{n-m} k$，绝对索引 $m$ 和 $n$ 在指数/三角恒等式中自然抵消，结果只取决于相对距离 $n-m$。
