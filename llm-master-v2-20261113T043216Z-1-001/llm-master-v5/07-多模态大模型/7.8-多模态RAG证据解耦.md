### 7.8 多模态 RAG：视觉事实与文字法规双路解耦 【⭐ 理解】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：在企业安全合规问答或医疗/金融审核中，既要看图片里的画面，又要查知识库里的制度条款。如果把“模糊不清的现场照片”和检索出来的“《高空作业严禁不系安全带》严厉法规”塞进同一个 Prompt 里让 VLM 一起看，大模型极易患上**“以法索图（倒果为因）”幻觉**——读到严厉法条后，硬把照片里一团模糊阴影脑补成“未系安全带”！或者引用了去年就已经废止的旧版制度！

本节解法：构建 MultimodalRAGVerifier（双路解耦核验引擎）：① 视觉盲审链（绝对不看法规条文，只客观输出 hazard / safe / unknown）；② 文本 RAG 链（独立检索并校验制度版本与 start_date <= as_of <= end_date 有效期）；③ 确定性后置门禁合流：只有视觉实锤且法规现行有效才放行，否则一律降级为 MANUAL_REVIEW。

大白话例子：就像法院审案必须“侦查取证”与“法条检索”分离：看监控录像的鉴证员不能先听检察官念一遍“盗窃罪判三年”再去看模糊视频，否则看谁都像小偷；鉴证员必须盲审先出客观报告“画面太暗看不清人脸（unknown）”，书记员再查法条是不是现行有效，最后法官（确定性门禁）一看画面看不清，直接判“证据不足，转人工实地复核”！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 视觉盲审观察 VisualObservation(case_id, observation, rule_id)、制度目录 RegulatoryRule(rule_id, version, start_date, end_date)、核查基准日期 as_of。 |
| ② 做什么 | 校验制度起止日期合法性 -> 若视觉为 unknown 或 safe 直接短路不借用法规脑补 -> 若视觉实锤 hazard，再核对 rule_id 是否存在且 as_of 在有效期内。 |
| ③ 输出什么 | 确定性分流状态（CONFIRMED_HAZARD / PASS_SAFE / MANUAL_REVIEW）及可审计原因。 |
| ④ 关键参数 | as_of（核查基准日期，解决跨年度旧规程过期问题）、视觉盲审隔离边界。 |
| ⑤ 工程 Trade-off | 双路解耦比单次端到端 Prompt 多一次调用，但物理切断了“语言先验污染视觉判断”的通道，并天然支持制度版本审计与回溯。 |

#### 3. 💻 渐进式代码实操（Step 8：MultimodalRAGVerifier 双路解耦核验）

演进说明：把 Step 6 的 unknown 拒答机制与文本 RAG 结合，实现“看图与查法物理隔离 + 法规时效硬门禁”。

```python
"""7.8 Step 8: 多模态 RAG 视觉观察与制度法规双路解耦核验器.

彻底阻断“以法索图（看了严厉法规就脑补模糊画面违规）”幻觉：
1. 视觉盲审链（不看法规）只输出 hazard / safe / unknown。
2. 法规文本链独立校验 rule_id 存在性与 as_of_date 生效有效期。
3. 只有“视觉实锤 + 法规现行有效”才放行，否则一律确定性降级为 MANUAL_REVIEW。
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import date
from typing import Dict, List


@dataclass(frozen=True)
class RegulatoryRule:
    rule_id: str
    title: str
    version: str
    start_date: str
    end_date: str


@dataclass(frozen=True)
class VisualObservation:
    case_id: str
    observation: str  # "hazard" | "safe" | "unknown"
    rule_id: str


class MultimodalRAGVerifier:
    """双路解耦核验引擎：物理隔离视觉事实与法规检索."""

    def __init__(self, rules: List[RegulatoryRule]) -> None:
        if not rules:
            raise ValueError("制度库不能为空")
        self._rules: Dict[str, RegulatoryRule] = {}
        self._ranges: Dict[str, tuple[date, date]] = {}
        for r in rules:
            s, e = date.fromisoformat(r.start_date), date.fromisoformat(r.end_date)
            if s > e:
                raise ValueError(f"制度 {r.rule_id} 生效日期晚于失效日期")
            self._rules[r.rule_id] = r
            self._ranges[r.rule_id] = (s, e)

    def verify(self, obs: VisualObservation, as_of: date) -> Dict[str, str]:
        if obs.observation not in {"hazard", "safe", "unknown"}:
            raise ValueError(f"非法视觉观察状态: {obs.observation}")
        if obs.observation == "unknown":  # [必记设计决策-视觉证据不足直接降级人工复核防以法索图]
            return {"status": "MANUAL_REVIEW", "reason": "画面证据不足(unknown)，严禁凭法规脑补"}
        if obs.observation == "safe":
            return {"status": "PASS_SAFE", "reason": "视觉确认合规"}

        if obs.rule_id not in self._rules:  # [必记设计决策-缺失有效法规ID阻断自动化裁决]
            return {"status": "MANUAL_REVIEW", "reason": f"未检索到有效制度 {obs.rule_id}"}

        s_date, e_date = self._ranges[obs.rule_id]
        if not (s_date <= as_of <= e_date):  # [必背手撕-制度有效期区间硬门禁校验]
            return {
                "status": "MANUAL_REVIEW",
                "reason": f"制度 {obs.rule_id}({self._rules[obs.rule_id].version}) 不在有效期 [{s_date}, {e_date}]",
            }

        return {
            "status": "CONFIRMED_HAZARD",
            "reason": f"视觉实锤违规，且制度 {obs.rule_id}({self._rules[obs.rule_id].version}) 现行有效",
        }


if __name__ == "__main__":  # [无需死背-脚手架]
    verifier = MultimodalRAGVerifier(
        [
            RegulatoryRule("R-NEW", "高处作业规范", "v2026", "2026-01-01", "2027-12-31"),
            RegulatoryRule("R-OLD", "旧版安全规程", "v2023", "2023-01-01", "2025-12-31"),
        ]
    )
    today = date(2026, 11, 13)
    assert verifier.verify(VisualObservation("C1", "unknown", "R-NEW"), today)["status"] == "MANUAL_REVIEW"
    assert verifier.verify(VisualObservation("C2", "hazard", "R-OLD"), today)["status"] == "MANUAL_REVIEW"
    assert verifier.verify(VisualObservation("C3", "hazard", "R-NEW"), today)["status"] == "CONFIRMED_HAZARD"
    print("MM Step 8 self-test passed!")

```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：observation == "unknown" 永远只能落入 MANUAL_REVIEW；过期制度永远不能作为 CONFIRMED_HAZARD 的依据。

讲清关键行：MultimodalRAGVerifier 初始化即校验 start_date <= end_date 防止脏元数据入库；verify() 先判视觉客观事实，再查制度有效期，物理切断“以法索图”。

主动点出工程细节：生产中制度库还必须支持多租户/分厂区元数据过滤（A 厂区的内部规定不能拿去判 B 厂区的画面），且输出必须带上 version 和条款页码方便复核。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：模糊照片被系统误判为“严重违章”，还附带了一段说得头头是道的法规条文

现象：模型把法规当成了“图片里必然违规”的暗示。

定位方法：检查是否把法规条文和原图塞进同一个 VLM Prompt 里端到端提问。

修复方案：拆分为视觉盲审（不看法规）与文本 RAG 检索两路，用确定性门禁合流。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：什么是多模态 RAG 中的“以法索图”幻觉？怎么根治？

参考答法：当检索出严厉的合规条款并和模糊图片一起喂给 VLM 时，模型的强语言先验会诱导它把噪点脑补成违规。根治方法就是双路物理隔离：视觉模型只盲审像素事实，文本 RAG 独立查现行有效条款，最后由宿主确定性逻辑合流。
