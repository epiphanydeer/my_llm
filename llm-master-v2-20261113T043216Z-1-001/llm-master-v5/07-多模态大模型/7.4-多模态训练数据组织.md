### 7.4 多模态训练数据组织与事件级防泄漏切分 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：在收集了几千张监控抓拍图准备微调或评测时，新手最爱写一句 random.shuffle() 按 8:2 切分训练集和测试集。结果测试集准确率高达 98%，一部署到新现场却暴跌到 45%——因为同一个摄像头几秒内连拍的图片背景一模一样，随机切分等于考前把原题透传给了测试集（事件级数据泄漏）！

本节解法：建立 EventSplitDatasetValidator（事件级防泄漏校验器）：① 强制以 event_id（同摄像头时段/同图裁切/同工地场景）为原子隔离边界，严禁跨 train/val/test 泄漏；② 保留规范的 unknown（不可判断）标注；③ 坚守 AIGC 合成数据防污染铁律。

大白话例子：就像学校出期末考卷：老师绝对不能把“同一张试卷的第 1 题放进练习册，第 2 题原封不动放进期末考”；监控连拍的 10 张照片就像同一个家庭户口本（event_id），分班时必须整户打包，要么全进训练集，要么全进测试集，绝不允许一家人两头跑！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 多模态数据清单 records（含 id、event_id、split、label、image_path 等元数据）。 |
| ② 做什么 | 校验必填字段与样本 ID 唯一性 -> 校验 split 和 label（含 unknown）合法性 -> 构建 event_id -> split 映射表并拦截跨分区重叠 -> 断言 train_events & test_events == set()。 |
| ③ 输出什么 | 通过校验的统计摘要（total、unique_events、split_counts、unknown_count），或精确抛出 DATA_LEAKAGE 异常。 |
| ④ 关键参数 | event_id 分组粒度（按摄像头连拍时段 / 按物理场地 / 按拍摄日期，粒度越粗测试越贴近真实跨域泛化）。 |
| ⑤ 工程 Trade-off | 事件级隔离会减少“虚高的验证集分数”，让训练前期看起来指标没那么好看，但测出来的才是真实新场景泛化下限，是上线前最可靠的照妖镜。 |

知识扩展（面试加分盲区）：

为什么模糊/遮挡样本不能丢掉，而要标为 unknown？：如果把看不清的样本全删掉，模型在训练时只见过清晰图片，上线遇到逆光或镜头起雾时就会“强行凭想象编造一个答案”（Hallucination）；把它们标为 unknown 参与训练，才能教会模型**“看不清就诚实拒答转人工”**的合规边界。

AIGC 合成数据增强的防污染铁律：用文生图/图生图合成稀缺隐患样本（如高空未系安全带）来扩充训练集时，必须遵守：① 测试集（Golden Test Set）100% 纯净真图，严禁混入任何一张合成图；② 合成图入库前过自动化检测/视觉定位门禁过滤畸变废片；③ 多光照/多天气打散防止模型学到合成纹理捷径（Shortcut Learning）。

#### 3. 💻 渐进式代码实操（Step 4：EventSplitDatasetValidator 防泄漏校验）

演进说明：在 Step 3 单样本图像校验基础上，上升到数据集清单级别的事件防泄漏切分与 unknown 样本合规检查。

```python
"""7.4 Step 4: 多模态训练数据组织与事件级防泄漏切分 (Event-Level Split).

在 Step 3 输入校验基础上新增数据集清单校验：
1. 强制每条样本包含规范字段且允许合规的 `unknown` 拒答标签。
2. 按 `event_id` 隔离划分 train/validation/test，严禁同一事件的连拍帧跨集合泄漏。
"""

from __future__ import annotations

from typing import Dict, List, Set


VALID_SPLITS = frozenset({"train", "validation", "test"})
VALID_LABELS = frozenset({"hazard", "safe", "unknown"})  # [必记设计决策-显式保留unknown拒答合规类别]


def validate_event_split_dataset(records: List[Dict[str, str]]) -> Dict[str, object]:
    """校验字段完整性、样本 ID 唯一性，并阻断跨分区事件级数据泄漏."""
    if not records:
        raise ValueError("数据集不能为空")

    seen_ids: Set[str] = set()
    event_to_split: Dict[str, str] = {}
    split_counts: Dict[str, int] = {s: 0 for s in VALID_SPLITS}
    unknown_count = 0

    for idx, row in enumerate(records, start=1):
        for key in ("id", "event_id", "split", "label"):
            if not str(row.get(key, "")).strip():
                raise ValueError(f"第 {idx} 条样本缺少必填字段: {key}")

        sid = row["id"].strip()
        ev = row["event_id"].strip()
        sp = row["split"].strip()
        lb = row["label"].strip()

        if sid in seen_ids:
            raise ValueError(f"发现重复样本 ID: {sid}")
        seen_ids.add(sid)

        if sp not in VALID_SPLITS:
            raise ValueError(f"非法分区 {sp}，必须属于 {VALID_SPLITS}")
        if lb not in VALID_LABELS:
            raise ValueError(f"非法标签 {lb}，必须属于 {VALID_LABELS}")

        if ev in event_to_split and event_to_split[ev] != sp:  # [必背手撕-按event_id隔离防止连拍帧跨集泄漏]
            raise ValueError(
                f"DATA_LEAKAGE: 事件 {ev} 同时出现在 {event_to_split[ev]} 与 {sp}！"
            )
        event_to_split[ev] = sp
        split_counts[sp] += 1
        if lb == "unknown":
            unknown_count += 1

    train_events = {r["event_id"] for r in records if r["split"] == "train"}
    test_events = {r["event_id"] for r in records if r["split"] == "test"}
    assert len(train_events & test_events) == 0, "训练集与测试集存在事件交集！"  # [必记设计决策-训练与测试事件零交集断言]

    return {
        "total": len(records),
        "unique_events": len(event_to_split),
        "split_counts": split_counts,
        "unknown_count": unknown_count,
    }


if __name__ == "__main__":  # [无需死背-脚手架]
    clean_rows = [
        {"id": "s1", "event_id": "cam01_1000", "split": "train", "label": "hazard"},
        {"id": "s2", "event_id": "cam01_1000", "split": "train", "label": "unknown"},
        {"id": "s3", "event_id": "cam02_1400", "split": "test", "label": "safe"},
    ]
    summary = validate_event_split_dataset(clean_rows)
    assert summary["unique_events"] == 2 and summary["unknown_count"] == 1
    print(f"MM Step 4 self-test passed! summary={summary}")

```

### 🧠 代码区记忆清单：背什么 vs 不背什么

- **🔒 不可替代的系统设计决策**：数据集必须按 `event_id` 做事件级隔离切分，严禁同一监控事件的连拍帧跨越 `train/validation/test` 造成数据泄漏；标签集合需显式保留 `unknown` 合规拒答类。
- **✍️ 面试手撕/默写范围**：手写 `event_to_split` 映射冲突检测与 `train_events & test_events == set()` 零交集断言。
- **🗑️ 无需死背的脚手架代码**：必填字段遍历校验、分区计数统计、`__main__` 测试及 `sklearn.model_selection.GroupShuffleSplit` 调库写法。

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：train_events & test_events == set() 是防泄漏铁律；同一 event_id 下的所有连续帧和同图裁切样本只能归属同一个 split。

讲清关键行：event_to_split 哈希表在 $O(N)$ 单遍扫描内即可抓出任何跨区事件泄漏；同时显式放行并统计 unknown 样本，避免清洗脚本误删拒答数据。

主动点出工程细节：如果数据里还存在跨摄像头的近似重复图（如不同角度拍同一物体），除了 event_id 隔离，还可以加 pHash（感知哈希）/ Embedding 余弦相似度去重作为第二道防泄漏门禁。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：线下验证集准确率 95%，部署到新工地直接跌到 50%

现象：模型在新环境几乎失效。

定位方法：优先检查 train 和 test 是否按行随机切分导致同一摄像头背景同时出现在两边（数据泄漏）；其次检查新旧工地的光照/设备型号分布偏移（Domain Shift）。

修复方案：改用按场地/事件编号的 GroupShuffleSplit 重建验证集，并补采新工地少量无泄漏样本做域适应。

故障 2：模型面对全黑或大雾遮挡镜头时，依然自信地输出“未系安全带”

现象：恶劣天气下误报率飙升。

定位方法：检查训练集标注规范，发现模糊样本全被丢弃或被强行标成了二分类。

修复方案：引入 unknown 拒答样本参与训练与评测。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么多模态监控/巡检数据集绝对不能按样本行随机 Train/Test Split？

参考答法：监控连拍帧或同图不同裁剪区域的背景纹理几乎一模一样。随机切分会让模型通过记住特定背景（如某个脚手架角落）在测试集上“作弊”拿高分，一旦部署到新场地背景变化，准确率立刻雪崩。必须按 event_id 或物理场地整包隔离切分。

Q2：使用 AIGC 合成数据扩充训练集时，最重要的两条红线是什么？

参考答法：① 测试集必须 100% 纯净真图，绝不混入合成图自嗨；② 合成图入库前必须过质量门禁（过滤畸变和图文不符），防止模型学到假图纹理伪影。
