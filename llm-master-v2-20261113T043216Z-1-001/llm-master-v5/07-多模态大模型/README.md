# 第七章 多模态大模型：渐进式面试备考全集

本章围绕**「工业巡检与安全合规多模态系统」**统一实战场景，保留原仓库全部多模态图文理论与核心配图，并按 Step 1 ~ Step 10 渐进式叠加工业级工程模块（空间评测 -> 视觉编码 -> 输入校验 -> 防泄漏数据 -> SFT 掩码 -> 切片混淆矩阵 -> 视频抽帧 -> 双路 RAG 解耦 -> 成对消融 -> 分级级联降本）。

## 本章要学会什么

- **能回答的设计题。** 能为矿山巡检设计检测、VLM 复核、制度检索与人工复审，解释小目标、低照度和视频对齐的难点。
- **能提供的验证证据。** 用按事件隔离的测试集报告漏报、拒答和夜间退化，对照高低分辨率方案的 P95 与每次成功任务成本。重点看 7.1–7.4、7.6、7.8–7.10。
- **代码练到哪。** 闭卷练 7.1 的 IoU／NMS 和 7.2 的 Patchify。7.5 的 -100 标签与移位留给训练方向或简历追问。

## 本章总结：项目设计与评测系统

先用一张图讲清请求、状态和失败出口，再用相同输入说明如何对照、如何评分、何时可以上线。下列案例可用作白板练习。

### 案例 1 · 夜间现场巡检的视觉复核

**面试官可能问**　低清画面里看不清安全带，怎么设计检测、VLM 复核与人工确认？

```text
视频时间戳抽帧 → 检测候选区域 → 低置信样本走高清 ROI → 视觉事实 → 规则核验 → 复核队列
```

**系统设计**　保留帧时间、ROI 坐标和可见性。VLM 输出看见了什么以及哪里看不清，适用规程由另一条链路检索。高风险或不可判的帧升级到更强证据或人工，测试环境用模拟告警状态。

**评测系统**　测试集按事件分组，分别标框、可见性、事实与是否可裁决。对比 YOLO 单路、整图 VLM、YOLO 加 ROI。按夜间、小目标和遮挡报严格召回、误报、人工复核量、P95 和每成功任务成本。

**常见追问与排障**　过强的 NMS 抑制可能造成密集目标漏检，低清或裁剪过紧可能裁掉证据。按错例回放原帧到最终结果，分清漏在哪里。

**现场参考回答**

> 我会把看见什么和是否违反规则拆开。用关键切片的漏报检查低成本方案，用人工复核量约束升级阈值。

### 案例 2 · 视频事件定位，短时异常怎么发现

**面试官可能问**　现场视频帧率可变，某个异常只持续几秒。怎样定位开始结束、验证漏检？

```text
按 PTS 对齐 → 低频全局抽样 → 候选窗口高频复查 → 融合事件区间 → 输出证据时间段
```

**系统设计**　用实际时间戳定位，保留原视频与采样配置。低频负责扫查，短时高风险类需按场景设置最低采样密度或触发源。局部复查合并重复事件，低置信结果转人工。

**评测系统**　按事件建立带起止时间和类型的评测集，覆盖短事件、可变帧率、无事件和相邻事件。对照固定采样和自适应采样。测事件级召回、时间段重合或边界误差、重复告警、漏检与每视频处理成本。

**常见追问与排障**　短事件漏检先查看标注时间段是否有帧被抽中，再查已抽中帧模型能否识别。前者调采样密度，后者查清晰度与模型。

**现场参考回答**

> 我会先把漏检拆成没见到帧和见到帧没识别。两类错误用不同参数修，也用不同的回放验证。
