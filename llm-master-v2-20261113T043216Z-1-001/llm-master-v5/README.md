## Agent 与多模态面试复习入口

**先练项目设计。** 先读第 3、4、7 章，再用第 2 章补齐接口工程。拿矿山巡检或规程问答当例子，从需求、数据、方案取舍讲到参数变化和失败证据。第 5、6、8、9 章按简历与岗位侧重深入。第 1、10 章用来补原理和准备选型题。

**再选短代码练到能独立写。** 应用主线优先练结构校验与工具回传（2.4、2.5、4.1、4.4 合练），检索归一化、融合和指标（3.4、3.7、3.9），以及视觉 IoU、NMS 和 Patchify（7.1、7.2）。采样（1.4）与最小 Attention、拆合头（9.1、9.2）是底层短题。微调、KV Cache、RoPE 等按 JD 和简历经历加练。

代码块内的 `【闭卷练习开始】` 和 `【闭卷练习结束】` 圈出要能独立写的几行。`【按岗位加练开始】` 对应训练、模型、部署或通用编码轮等具体方向。复习时用小输入验对边界行为，完整工程示例另用于理解和改写。

**专练系统设计和评测。** 每章 README 末尾有两个白板案例。做完单章后，用[综合项目面试案例](%E7%BB%BC%E5%90%88%E9%A1%B9%E7%9B%AE%E9%9D%A2%E8%AF%95%E6%A1%88%E4%BE%8B.md)练企业规程问答、矿山视频巡检和设备维修 Agent 三道完整设计题。

**每节用四个问题自测。** 面试官怎么问？我怎么选？参数调大或调小会怎样？系统出错时先查哪个证据、如何确认修复？每篇末尾有对应的场景和复习要求。招聘流程中也可能有独立的通用编程轮，按目标公司的轮次准备。[微软技术面试说明](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing.html)
