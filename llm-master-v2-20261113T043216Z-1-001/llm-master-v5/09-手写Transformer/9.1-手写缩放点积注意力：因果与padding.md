### 9.1 手写缩放点积注意力：因果与 Padding 双重掩码 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：手写 Attention 时，90% 的候选人只记得 softmax(Q @ K.T / sqrt(d_k)) @ V，一到面试追问“变长句子加了 Padding 后怎么屏蔽？如果某一行全被屏蔽成 -inf 导致 softmax 算出 NaN 怎么办？”立刻写崩！

本节解法：手写工业级 Dual-Masked Scaled Dot-Product Attention：① 因果上三角掩码（causal=True）；② Key Padding 广播掩码（key_padding_mask）；③ 防 NaN 安全 safe_softmax（整行全 -inf 时把输出概率置 0.0）。

大白话例子：就像在图书馆找书：第一条规矩（因果掩码）是“只能看已经出版的历史书，不能偷看明天还没写出来的书”；第二条规矩（Padding 掩码）是“书架后面为了凑整齐塞的空白假书（PAD）千万别算进参考文献”；安全 safe_softmax 则是“万一某页全是假书没一本能看，直接交白卷（全 0），绝不除以零搞炸计算器（NaN）”！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | q: (..., T_q, d_k)、k: (..., T_k, d_k)、v: (..., T_k, d_v)、causal: bool、key_padding_mask: (B, T_k)。 |
| ② 做什么 | 计算缩放点积 scores -> 叠加因果上三角掩码与广播对齐的 Padding 掩码（置 -np.inf）-> 执行防全掩码 NaN 的 safe_softmax -> 加权求和 attn_weights @ v。 |
| ③ 输出什么 | (out, attn_weights)，输出形状 (..., T_q, d_v)，且所有掩码位置权重严格为 0.0。 |
| ④ 关键参数 | causal、key_padding_mask（True 有效，False 为 PAD）。 |
| ⑤ 工程 Trade-off | 用 Key Masking（屏蔽列）而非 Query Masking（屏蔽行），避免某行全被掩码后引发 0/0 = NaN 污染整个 Batch 梯度；即便极端情况下出现全 -inf 行，也由 safe_softmax 兜底归零。 |

#### 3. 💻 渐进式代码实操（Step 1：双重掩码安全注意力内核）

演进说明：第 9 章积木 1 号，构建后续多头注意力与完整 Transformer 的核心算子底座。

```python
"""9.1 Step 1: 手写缩放点积注意力 (因果上三角掩码 + Key Padding 掩码 + 防 NaN 安全 Softmax)."""

from __future__ import annotations

import math
from typing import Optional
import numpy as np


def safe_softmax(scores: np.ndarray, axis: int = -1) -> np.ndarray:
    """数值稳定 Softmax：减去最大值防溢出，且若整行被掩码为 -inf 则置 0 防 NaN."""
    # 【闭卷练习开始】稳定 Softmax 和全遮挡。白板版先把全遮挡行的最大值替换为 0，再做减法
    max_val = np.max(scores, axis=axis, keepdims=True)  # 安全Softmax。减去最大值防 exp 溢出
    is_all_masked = np.isneginf(max_val)  # 全遮挡防NaN。整行被 Mask 时 -inf - (-inf) 会产生 NaN，必须显式兜底置 0
    shifted = np.where(is_all_masked, -1e9, scores - max_val)  # 防NaN平移。全遮挡行替换安全负值避免产生 NaN
    exp_x = np.exp(shifted)
    exp_x = np.where(is_all_masked, 0.0, exp_x)
    denom = np.sum(exp_x, axis=axis, keepdims=True)
    return np.where(denom > 0.0, exp_x / np.maximum(denom, 1e-12), 0.0)
    # 【闭卷练习结束】


def scaled_dot_product_attention(
    q: np.ndarray,
    k: np.ndarray,
    v: np.ndarray,
    causal: bool = True,
    key_padding_mask: Optional[np.ndarray] = None,
) -> tuple[np.ndarray, np.ndarray]:
    if q.shape[-1] != k.shape[-1] or k.shape[-2] != v.shape[-2]:  # 脚手架。输入张量维度校验
        raise ValueError(f"Q/K/V 维度不匹配: q={q.shape}, k={k.shape}, v={v.shape}")

    # 【闭卷练习开始】缩放点积、因果和 padding 掩码、权重乘 V
    d_k = q.shape[-1]
    t_q, t_k = q.shape[-2], k.shape[-2]
    scores = (q @ np.swapaxes(k, -1, -2)) / math.sqrt(d_k)  # 缩放点积。(..., T_q, d_k) @ (..., d_k, T_k) / sqrt(d_k)

    if causal:
        causal_mask = np.triu(np.ones((t_q, t_k), dtype=bool), k=1)  # 因果上三角掩码。k=1 严格屏蔽未来 token
        scores = np.where(causal_mask, -np.inf, scores)  # 先Mask后Softmax。置为 -inf 使 Softmax 后权重严格归零

    if key_padding_mask is not None:
        pad_mask = ~key_padding_mask  # Padding掩码对齐。取反并扩维广播至 scores 形状
        while pad_mask.ndim < scores.ndim:
            pad_mask = np.expand_dims(pad_mask, axis=1)
        scores = np.where(pad_mask, -np.inf, scores)

    attn_weights = safe_softmax(scores, axis=-1)
    out = attn_weights @ v  # 价值加权聚合。(..., T_q, T_k) @ (..., T_k, d_v)
    assert out.shape == (*q.shape[:-1], v.shape[-1]) and np.isfinite(out).all()
    return out, attn_weights
    # 【闭卷练习结束】


if __name__ == "__main__":  # 脚手架。双重掩码自测入口
    rng = np.random.default_rng(42)
    q, k, v = rng.normal(size=(2, 4, 8)), rng.normal(size=(2, 4, 8)), rng.normal(size=(2, 4, 8))
    pad_mask = np.array([[True, True, True, True], [True, True, False, False]])
    out, weights = scaled_dot_product_attention(q, k, v, causal=True, key_padding_mask=pad_mask)
    assert np.allclose(weights[0, 0, 1:], 0.0) and np.allclose(weights[1, :, 2:], 0.0)
    print("Ch9 Step 1 self-test passed!")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：out 绝不允许出现 NaN/Inf；上三角与 PAD 列权重必须严格为 0.0。

讲清关键行：is_all_masked = np.isneginf(max_val) 解决了整行全 -inf 时 (-inf) - (-inf) = NaN 的经典数值陷阱；while pad_mask.ndim < scores.ndim 自动适配 3D 单头与 4D 多头。

主动点出工程细节：左 Padding（Left-Padding）在批量生成推理中非常常见，确保所有样本的最后一个真实 Token 对齐到最右侧！

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：Encoder 双向批处理遇到全 PAD 的空占位样本，训练直接出 NaN

现象：某个 Batch 里混入一条全空白样本，整批梯度炸成 NaN。

定位方法：朴素 F.softmax 对全 -inf 行返回 NaN。

修复方案：使用 safe_softmax 兜底全 -inf 行置 0，或在数据加载器过滤全空样本。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么屏蔽 Padding 时只屏蔽 Key（列），通常不屏蔽 Query（行）？

参考答法：屏蔽 Key 能保证每个有效 Query 不会从 PAD 位置吸取噪音；而 PAD 位置自己的 Query 行就算算了，在算最终 Loss 时也会被 labels=-100 忽略。如果强行把整行 Query 置 -inf，直接触发 0/0 = NaN 污染反向传播！

## 面试重点｜设计、调参与排障

**面试官可能问**

白板实现带因果掩码的注意力，整行被遮挡时怎么办？

**参考回答（现场口述）**

先算 QK 转置除以根号头维，掩掉未来和 padding，再做稳定 softmax 乘 V。全遮挡行若直接对负无穷做减最大值会有 NaN，要单独识别并返回零权重。白板配一个含全遮挡行的小例子验证。

**系统设计怎么选**

先算 QK 转置并除根号 d，在 softmax 前合入可见性，再乘 V。沿 key 轴做稳定归一。先识别全遮挡行，再避免对无效值做平移。

**参数或条件改变会怎样**

区分 bool mask 的真假语义与加性 mask。全遮挡行可约定权重为零，低精度下不要依赖随手选的有限负常数。

**系统出错怎么查、怎么验证**

练普通行、未来位置、全遮挡。例子里的 np.where 仍可能先计算无效减法并告警，闭卷实现可先换掉全遮挡行的平移最大值。
