### 9.5 手写 TransformerBlock：Pre-LN、注意力与 FFN 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：我们已经手搓好了 Step 2 的 MultiHeadAttention、Step 3 的 SwiGLUFeedForward 和 Step 4 的 RMSNorm，现在需要把它们按正确的拓扑顺序缝合成一个完整的 Pre-LN TransformerBlock。

本节解法：实现 TransformerBlock，严格执行 h = x + self.attn(self.norm1(x)) 与 out = h + self.ffn(self.norm2(h)) 双重残差连接，透传 causal 与 key_padding_mask。

大白话例子：把前面造好的“多头发动机（MHA）”、“智能混水阀（SwiGLU）”和“稳压器（RMSNorm）”装进一个标准集装箱（Block）里，留下完全对齐的 (B, T, C) 进出口，接下来想叠几层就叠几层！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | x: (B, T, C)、causal: bool、key_padding_mask: (B, T)。 |
| ② 做什么 | h = x + attn(norm1(x)) -> out = h + ffn(norm2(h))。 |
| ③ 输出什么 | (B, T, C)。 |
| ④ 关键参数 | d_model、num_heads、d_ff。 |
| ⑤ 工程 Trade-off | 两个独立的 norm1 与 norm2 不可共享参数，因为 Attention 输入分布和 FFN 输入分布截然不同。 |

#### 3. 💻 渐进式代码实操（Step 5：Pre-LN TransformerBlock 拼装）

演进说明：把 Step 2、Step 3、Step 4 三个独立积木正式组装成一个完整 Block。

```python
"""9.5 Step 5: 手写标准 Pre-LN TransformerBlock (RMSNorm + MHA + SwiGLU 双重残差闭环)."""

from __future__ import annotations

from typing import Optional
import numpy as np
from step_02 import MultiHeadAttention
from step_03 import SwiGLUFeedForward
from step_04 import RMSNorm


class TransformerBlock:
    """Pre-LN 架构：x = x + MHA(RMSNorm(x)); x = x + FFN(RMSNorm(x))."""

    def __init__(self, d_model: int, num_heads: int, d_ff: int, seed: int = 42) -> None:
        self.norm1 = RMSNorm(d_model)  # 脚手架。子层组件实例化
        self.attn = MultiHeadAttention(d_model, num_heads, seed=seed)
        self.norm2 = RMSNorm(d_model)
        self.ffn = SwiGLUFeedForward(d_model, d_ff, seed=seed + 1)

    def forward(
        self,
        x: np.ndarray,
        causal: bool = True,
        key_padding_mask: Optional[np.ndarray] = None,
    ) -> np.ndarray:
        # 【按岗位加练开始】模型岗练两次 Pre-LN 残差
        h = x + self.attn.forward(self.norm1.forward(x), causal=causal, key_padding_mask=key_padding_mask)  # Pre-LN注意力残差。先 Norm 再进 Attention，最后与原输入 x 相加
        out = h + self.ffn.forward(self.norm2.forward(h))  # Pre-LN前馈残差。先 Norm 再进 SwiGLU，保留主干梯度高速公路
        assert out.shape == x.shape  # 形状不变性。任意 Block 输入输出同为 (B, T, C) 才能任意堆叠
        return out
        # 【按岗位加练结束】


if __name__ == "__main__":  # 脚手架。自测入口
    blk = TransformerBlock(d_model=16, num_heads=4, d_ff=48)
    x = np.random.default_rng(5).normal(size=(2, 6, 16))
    assert blk.forward(x).shape == (2, 6, 16)
    print("Ch9 Step 5 self-test passed!")
```

### 示例说明与练习范围

本例的设计选择：Pre-LN 顺序（Norm -> Sublayer -> + Residual）与 Block 输入输出 (B, T, C) 严格同形约束。

**代码练习｜按岗位加练**。会写两次加法和归一的位置，完整组装类按岗位加练。

示例辅助代码：__init__ 成员实例化、随机数种子偏移 seed + 1 与 __main__ 形状断言。

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：norm1 与 norm2 权重独立；残差加法左侧永远是未经 Norm 的主干流 x 和 h；输出形状恒等于输入形状 (B, T, C)。

讲清关键行：causal 与 key_padding_mask 仅传给 self.attn，因为 ffn 和 norm 都是逐 Token 独立运算的，不存在跨位置信息泄漏。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：错误地让 norm1 和 norm2 共用同一个 RMSNorm 实例

现象：模型训练收敛明显变慢。

修复方案：为 Attention 前和 FFN 前各自实例化独立的 RMSNorm。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么 key_padding_mask 只需要传给 Attention，不需要传给 FFN 和 RMSNorm？

参考答法：FFN 和 RMSNorm 都是严格逐位置（Position-wise）独立计算的，第 i 个 Token 不会读取第 j 个 Token；只有 Attention 存在跨位置混合，才需要掩码屏蔽 PAD。

## 面试重点｜设计、调参与排障

**面试官可能问**

一层 Pre-LN Block 两条残差怎么走？

**参考回答（现场口述）**

第一条先对 x 做 Norm，再算 Attention，加回 x。第二条用第一次残差的结果先 Norm，再算 FFN，加回当时的状态。验证两条支路分别接到正确的输入，并保留因果掩码。

**系统设计怎么选**

先把归一后的输入送进 Attention，与原输入相加，再把更新后的值归一后送进 FFN，加回第二条残差。mask 传给 Attention。

**参数或条件改变会怎样**

替换 FFN、Norm 或 Dropout 前先固定拓扑，看梯度与回归。推理等价测试时禁用随机项。

**系统出错怎么查、怎么验证**

把两个子层替换为返回零，Pre-LN 的示例应保持输入。用这个检查残差是否用了正确变量。
