# 1.8 学习路线：复述、手写、排障与复习【⭐ 理解】

## 1. 🎯 本节目标与大白话例子

本节目标：建立科学的大模型备考与工程内化闭环：用“费曼复述 + 核心手写 + 排障日志 + 间隔复习”代替低效的纯刷八股文。

大白话例子：学游泳光看泳姿图解（只看不写）下水还是会呛水；把每次呛水的原因记下来（排障日志），隔几天再下水练一趟（间隔复习），才算真正长在身上的肌肉记忆。

## 2. 🧠 核心原理与五维拆解

四步内化闭环：

复述（Feynman）：合上笔记，用 2 分钟大白话向非技术同事讲清原理与取舍。

手写（Code）：核心模块（如 Attention、BPE、Sampling、Tool Loop）不看提示能在白板/IDE 写出可运行最小版本与断言测试。

排障（Debug）：把遇到过的报错（维度不匹配、OOM、缓存未命中、JSON 截断）写成“现象→根因→解法”。

间隔复习（Spaced Repetition）：按 1→2→4→8→16→30 天节奏复盘薄弱节点，未过关节点重置为 1 天。

## 3. 💻 渐进式代码实操（ch1_code/step_08_spaced_review_scheduler.py）

```python
"""1.8 学习路线：复述、手写、排障与间隔复习调度器"""
from dataclasses import dataclass
from datetime import date, timedelta
from typing import List


@dataclass
class KnowledgeNode:  # 脚手架。知识节点状态数据结构
    topic: str
    feynman_passed: bool
    code_tested: bool
    troubleshoot_logged: bool
    last_review: date
    interval_days: int = 1

    def next_review_date(self) -> date:
        if not (self.feynman_passed and self.code_tested):  # 掌握度双门禁。复述与手写跑通任一未过则次日重测
            return self.last_review + timedelta(days=1)
        next_iv = min(30, self.interval_days * 2)  # 指数间隔封顶。通过后间隔翻倍并封顶30天
        return self.last_review + timedelta(days=next_iv)


def due_topics(nodes: List[KnowledgeNode], today: date) -> List[str]:
    return [n.topic for n in nodes if n.next_review_date() <= today]  # 到期任务筛选


if __name__ == "__main__":  # 脚手架。日期样例与断言
    today = date(2026, 11, 13)
    nodes = [
        KnowledgeNode("1.4 采样参数", True, True, True, date(2026, 11, 10), interval_days=1),
        KnowledgeNode("1.6 Token口径", True, True, True, date(2026, 11, 10), interval_days=4),
    ]
    due = due_topics(nodes, today)
    assert due == ["1.4 采样参数"]
    print("[1.8 PASS] due today:", due)
```

## 面试重点｜设计、调参与排障

**面试官可能问**

怎么准备项目追问，才不会只记住词？

**参考回答（现场口述）**

我给每个项目准备一个设计题和一个事故题。先讲任务与约束，再讲我做的决策、放弃了什么、怎么用数据验证。最后准备一个能跑的小核心和一条真实失败轨迹，方便面试官沿着我的工作追问。

**系统设计怎么选**

每个主线问题准备一个真实场景、一项决策、一个失败样本和验收指标。例如夜间小目标漏报时，为什么先查输入尺寸。

**参数或条件改变会怎样**

复习时间按岗位分配。先练项目链路和高价值核心小函数，再练岗位相关算子。

**系统出错怎么查、怎么验证**

闭卷讲完后追问自己“还会在哪种输入上失败”“改完怎么知道有效”。缺答案就回到错例。
