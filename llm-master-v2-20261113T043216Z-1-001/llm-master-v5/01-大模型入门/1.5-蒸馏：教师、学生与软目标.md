# 1.5 蒸馏：教师、学生与软目标【⭐ 理解】

## 1. 🎯 本节目标与大白话例子

本节目标：理解知识蒸馏（Knowledge Distillation）中“教师模型、学生模型、软目标（Soft Targets）与温度 $T$”的核心原理，区分黑盒响应蒸馏与白盒 Logits 蒸馏。

大白话例子：硬标签（Hard Label）就像标准答案只写“选 A”；而教师模型的软目标（Soft Target）就像学霸的草稿纸：“选 A 把握 85%，B 有 12% 迷惑性，C 和 D 几乎不可能”。学生看懂这种“类间相似度分布”，比死记硬背答案学得快得多。

## 2. 🧠 核心原理与五维拆解

图片待恢复：原图

是什么（What）：用参数量大、能力强的 Teacher 模型指导轻量级 Student 模型训练，在大幅降低推理延迟与显存成本的同时尽可能保留精度。

两大工程范式：

白盒 Logits 蒸馏：最小化带温度 $T$ 的 KL 散度 $\mathcal{L}_{KD} = \alpha T^2 \cdot \text{KL}(p_T \parallel q_T) + (1-\alpha) \text{CE}(y, q_1)$。

黑盒响应/推理链蒸馏（大模型最常用）：直接用强模型（如 DeepSeek-R1 / GPT-4o）生成高质量 推理过程与最终答案，清洗验证后作为 SFT 数据微调 7B/8B 小模型。

为什么乘 $T^2$：温度 $T$ 放大后，Softmax 输出的梯度幅值会缩小约 $1/T^2$，乘以 $T^2$ 才能保证软目标梯度与硬标签梯度在同一量级。

## 3. 💻 渐进式代码实操（ch1_code/step_05_distillation_kl.py）

```python
"""1.5 蒸馏：教师、学生与软目标 KL 散度损失计算"""
import numpy as np


def softmax_with_temp(logits: np.ndarray, temp: float) -> np.ndarray:
    scaled = logits / temp  # 高温软化分布。除以温度 T 放大次优类别信息
    scaled = scaled - np.max(scaled)
    e = np.exp(scaled)
    return e / np.sum(e)


def distillation_loss(  # 脚手架。损失函数签名与默认超参
    teacher_logits: np.ndarray,
    student_logits: np.ndarray,
    hard_label_idx: int,
    temperature: float = 2.0,
    alpha: float = 0.7,
) -> float:
    """Hinton 知识蒸馏总损失：alpha * T^2 * KL(p_T || q_T) + (1 - alpha) * CE(y, q_1)。"""
    p_t = softmax_with_temp(teacher_logits, temperature)
    q_t = softmax_with_temp(student_logits, temperature)
    eps = 1e-12
    kl_soft = float(np.sum(p_t * np.log((p_t + eps) / (q_t + eps))))  # 软目标KL散度。教师与学生高温概率分布对齐
    q_1 = softmax_with_temp(student_logits, 1.0)
    ce_hard = float(-np.log(q_1[hard_label_idx] + eps))
    return round(alpha * (temperature ** 2) * kl_soft + (1.0 - alpha) * ce_hard, 6)  # T平方梯度补偿。乘以 T^2 保持软硬损失梯度量级一致


if __name__ == "__main__":  # 脚手架。蒸馏损失单调性验证
    t_logits = np.array([5.0, 2.5, 0.5])
    s_bad = np.array([1.0, 3.0, 2.0])
    s_good = np.array([4.8, 2.4, 0.6])
    loss_bad = distillation_loss(t_logits, s_bad, hard_label_idx=0)
    loss_good = distillation_loss(t_logits, s_good, hard_label_idx=0)
    assert loss_good < loss_bad
    print("[1.5 PASS] loss_bad:", loss_bad, "loss_good:", loss_good)
```

### 示例说明与练习范围

## 4. 🗣️ 面试官视角：这段代码怎么讲

在实际业务里，如果能拿到同词表模型的 Logits，我会用带 $T^2$ 缩放的 KL 散度做白盒蒸馏；如果是跨词表或闭源强模型，最划算的做法是黑盒响应蒸馏——用大模型批量合成带推理链和验证过滤的 SFT 数据集去喂给 7B/14B 模型。

## 5. 🔧 生产排障指南

坑 1：直接拿大模型生成的错误样本去蒸馏学生模型 → 解法：黑盒蒸馏前必须经过规则/单测/人工或强裁判模型（Rejection Sampling）过滤，确保“老师讲对的才学”。

坑 2：白盒蒸馏时 Teacher 和 Student 词表不一致 → 解法：跨词表无法直接算逐 Token KL 散度，需先做词表对齐或直接改用黑盒数据蒸馏。

## 6. ❓ 高频面试追问与参考答法

Q1：白盒蒸馏中为什么需要升高温度 $T$？ 答：高温 $T > 1$ 会平滑 Teacher 的概率分布，把原本接近 0 的负类概率差异（Dark Knowledge）放大出来，让学生学到更丰富的类间关系。

Q2：大模型时代的“合成数据蒸馏”与传统 Hinton 蒸馏有什么异同？ 答：核心思想都是用强模型迁移能力到小模型；区别在于传统蒸馏靠 Softmax 概率分布传递暗知识，而大模型时代常通过强模型生成的思维链（CoT / Reasoning Trace）在文本空间传递“思考步骤”。

## 面试重点｜设计、调参与排障

**面试官可能问**

小模型替换大模型，什么时候考虑蒸馏？

**参考回答（现场口述）**

当任务比较稳定、大模型质量够高却长期太贵或太慢，而且有足够可用的教师样本时，我会试蒸馏。先把教师错例筛掉，以独立测试集对照原学生、蒸馏学生和教师。若瓶颈是知识经常更新，我会先改检索。

**系统设计怎么选**

有教师 logits 时可学习候选间的概率关系。只有教师输出时可蒸馏通过核验的回答。先测小模型本身缺少哪些能力。

**参数或条件改变会怎样**

温度变大会摊平软分布，经典蒸馏用 T² 补偿软损失梯度量级。教师错误也会被传入学生。

**系统出错怎么查、怎么验证**

训练损失下降但漏报上升时，查看低光、小目标等切片中的教师质量和样本覆盖。
