### 6.3 量化原理（INT8 / INT4）与误差核验 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：70B 模型光 BF16 权重就要 140GB，单张 80GB A100 根本装不下；而且 Decode 阶段受限于显存带宽，每次从 HBM 搬运 140GB 权重太慢了！但直接粗暴四舍五入截断成 INT4，模型精度当场崩盘胡言乱语！

本节解法：手写 对称量化（INT8）与非对称量化（UINT8）算子，并用 MSE 与余弦相似度审计反量化保真度；深入拆解“为什么权重用对称量化、激活值用非对称量化”以及 AWQ / GPTQ 如何解决离群点问题。

大白话例子：就像把高精度小数（3.1415926）按比例尺缩放到只有 256 个刻度的整数尺子上：对称量化把 0 钉在尺子正中间（适合正负对称的权重）；非对称量化把尺子起点挪到最小值（Zero-point，适合全是正数的 ReLU 激活值，不浪费一半负刻度）！

知识扩展（面试加分盲区）：

为什么权重和激活值会有“离群点（Outliers）”导致量化崩溃？：少数几个权重或激活通道数值极大（比如普通值在 [-1, 1]，突然冒出一个 50.0），如果整张矩阵共用一个 scale，这一个 50.0 会把量程拉大 50 倍，导致其他 99.9% 的正常小权重全被挤压成 0 或 1，精度瞬间崩盘！

AWQ（Activation-Aware Weight Quantization）核心思想：并不是所有权重都一样重要！对应着**激活值幅度最大的那 1% 显著通道（Salient Channels）**的权重对输出影响最大；AWQ 通过缩放因子放大显著通道再做 INT4 量化，保护核心权重不失真，且无需反向传播、比 GPTQ 更不容易过拟合校准集。

#### 3. 💻 渐进式代码实操（Step 3：手写对称/非对称量化与保真度审计）

演进说明：实现 INT8 对称量化与 UINT8 非对称量化算子，并用余弦相似度检验反量化保真度。

```python
"""6.3 Step 3: 对称量化与非对称量化算子及反量化保真度审计 (MSE / 余弦相似度)."""

from __future__ import annotations

from typing import Dict
import numpy as np


def symmetric_quantize_int8(w: np.ndarray) -> tuple[np.ndarray, float]:
    """对称 INT8 量化 (zero_point = 0, q in [-127, 127])."""
    max_abs = float(np.max(np.abs(w)))
    scale = max(max_abs / 127.0, 1e-12)
    q = np.clip(np.round(w / scale), -127, 127).astype(np.int8)
    return q, scale


def asymmetric_quantize_uint8(act: np.ndarray) -> tuple[np.ndarray, float, int]:
    """非对称 UINT8 量化 (适配 ReLU/GELU 偏斜激活值, q in [0, 255])."""
    w_min, w_max = float(np.min(act)), float(np.max(act))
    scale = max((w_max - w_min) / 255.0, 1e-12)
    zp = int(np.clip(round(-w_min / scale), 0, 255))
    q = np.clip(np.round(act / scale) + zp, 0, 255).astype(np.uint8)
    return q, scale, zp


def audit_fidelity(orig: np.ndarray, recon: np.ndarray) -> Dict[str, float]:
    mse = float(np.mean((orig - recon) ** 2))
    denom = float(np.linalg.norm(orig) * np.linalg.norm(recon))
    cos_sim = float(np.sum(orig * recon) / max(denom, 1e-12))
    return {"mse": round(mse, 8), "cosine_sim": round(cos_sim, 6)}


if __name__ == "__main__":
    rng = np.random.default_rng(10)
    weights = rng.normal(0.0, 0.5, size=(128, 128)).astype(np.float32)
    q_w, s_w = symmetric_quantize_int8(weights)
    assert audit_fidelity(weights, q_w.astype(np.float32) * s_w)["cosine_sim"] > 0.999

    acts = np.maximum(0.0, rng.normal(1.5, 0.8, size=(64, 64))).astype(np.float32)
    q_a, s_a, zp_a = asymmetric_quantize_uint8(acts)
    assert audit_fidelity(acts, (q_a.astype(np.float32) - zp_a) * s_a)["cosine_sim"] > 0.999
    print("Ch6 Step 3 self-test passed!")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：scale 必须用 max(..., 1e-12) 做防零除保护（全零张量不崩溃）；量化值必须用 np.clip 严格卡在数据类型范围之内防整数溢出环绕。

讲清关键行：对称量化无 zp 计算更快，适合零均值权重；非对称量化引入 zp 把 [w_min, w_max] 严丝合缝塞满 [0, 255]，不浪费负半轴刻度。

主动点出工程细节：W4A16（仅权重量化为 INT4，激活保持 FP16）能省 75% 显存并加速低并发访存，但计算时仍需反量化回 FP16；而 W8A8 / FP8 在支持 Tensor Core 的新卡上能直接硬件加速高并发矩阵乘。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么大模型权重通常选对称量化，而激活值更倾向非对称量化？

参考答法：权重基本以 0 为中心正负对称，对称量化零点为 0、推理计算省去零点偏置项；激活值经过 ReLU/GELU/SiLU 后往往呈明显单侧偏斜分布，非对称量化用 zero_point 能把所有离散刻度都用在有效区间上，精度高得多。
