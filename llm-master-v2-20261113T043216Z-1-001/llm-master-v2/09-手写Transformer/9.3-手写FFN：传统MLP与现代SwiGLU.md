### 9.3 手写 FFN：传统 MLP 与现代 SwiGLU 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：早期 Transformer 的 FFN 只是两层线性层夹一个 ReLU（Linear -> ReLU -> Linear），在负半轴直接一刀切死归零（Dead ReLU）；现代大模型（LLaMA / Qwen / DeepSeek）早已全面升级为 SwiGLU（Swish Gated Linear Unit） 门控前馈网络！

本节解法：手写 SwiGLUFeedForward：先手写数值防溢出的 silu(x) = x * sigmoid(x)，再用两个并行升维矩阵 $W_{\text{gate}}$ 和 $W_{\text{up}}$ 做哈达玛逐元素门控相乘，最后经 $W_{\text{down}}$ 降维回 d_model。

大白话例子：传统 FFN 就像一个单阀门水龙头，水开大了就全放过去；SwiGLU 则是双阀门智能混水阀——一路（W_up）负责提供原始信息流，另一路（SiLU(W_gate)）当成智能调节旋钮，逐个维度精准控制哪些特征放行、哪些特征关小！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | x: (B, T, d_model)。 |
| ② 做什么 | gated = silu(x @ w_gate) * (x @ w_up) -> out = gated @ w_down。 |
| ③ 输出什么 | (B, T, d_model)。 |
| ④ 关键参数 | d_ff（传统 MLP 为 4 * d_model，SwiGLU 有 3 个矩阵，通常取 8/3 * d_model 并对齐到 128/256 的倍数以保持总参数量与计算量持平）。 |
| ⑤ 工程 Trade-off | SwiGLU 用 3 个矩阵替代 2 个矩阵，平滑非单调门控让梯度流更丰富，同等参数量下显著降低预训练 PPL；代价是多了一次矩阵乘法，工程上常把 w_gate 和 w_up 融合成一次大矩阵乘再切片。 |

#### 3. 💻 渐进式代码实操（Step 3：SwiGLUFeedForward 积木）

演进说明：第 9 章积木 3 号，实现现代大模型标配的 SwiGLU 门控前馈层。

```python
"""9.3 Step 3: 手写 SwiGLU 门控前馈网络 (SiLU(x @ W_gate) * (x @ W_up)) @ W_down."""

from __future__ import annotations

import numpy as np


def silu(x: np.ndarray) -> np.ndarray:
    """Swish / SiLU 激活函数: x * sigmoid(x)，使用 clip 防止 exp(-x) 溢出."""
    sig = 1.0 / (1.0 + np.exp(-np.clip(x, -50.0, 50.0)))
    return x * sig


class SwiGLUFeedForward:
    """现代大模型 (LLaMA/Qwen) 标配的 SwiGLU 门控前馈网络."""

    def __init__(self, d_model: int, d_ff: int, seed: int = 42) -> None:
        if d_model <= 0 or d_ff <= 0:
            raise ValueError("d_model 与 d_ff 必须为正整数")
        self.d_model = d_model
        self.d_ff = d_ff
        rng = np.random.default_rng(seed)
        scale = 0.02
        self.w_gate = rng.normal(0.0, scale, (d_model, d_ff))
        self.w_up = rng.normal(0.0, scale, (d_model, d_ff))
        self.w_down = rng.normal(0.0, scale, (d_ff, d_model))

    def forward(self, x: np.ndarray) -> np.ndarray:
        if x.ndim != 3 or x.shape[-1] != self.d_model:
            raise ValueError(f"输入必须为 (B, T, {self.d_model})")
        gated = silu(x @ self.w_gate) * (x @ self.w_up)
        out = gated @ self.w_down
        assert out.shape == x.shape
        return out


if __name__ == "__main__":
    ffn = SwiGLUFeedForward(d_model=16, d_ff=48)
    x = np.random.default_rng(1).normal(size=(2, 5, 16))
    out = ffn.forward(x)
    assert out.shape == (2, 5, 16) and np.isfinite(out).all()
    print("Ch9 Step 3 self-test passed!")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：silu 内部必须对 x 做 clip 防止大负数输入导致 exp(-x) 溢出；SwiGLU 逐元素门控相乘发生在 (B, T, d_ff) 高维空间。

讲清关键行：silu(x @ self.w_gate) * (x @ self.w_up) 是逐元素哈达玛积（*），不是矩阵乘（@）！

主动点出工程细节：为什么 Qwen/LLaMA 的 d_ff 总是奇奇怪怪的数字（如 11008、14336）？就是按 $\frac{2}{3} \times 4 d_{\text{model}}$ 算完后再向上对齐到 128/256 的倍数，以吃满 GPU Tensor Core 的硬件对齐效率！

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：手写 1 / (1 + exp(-x)) 在极端负激活下出现 OverflowError / RuntimeWarning 导致 NaN

定位方法：未对指数输入做范围截断。

修复方案：用 np.clip(x, -50.0, 50.0) 截断或直接调 F.silu。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么 SwiGLU 里的 d_ff 通常是 $\frac{8}{3} d$ 而不是传统 MLP 的 $4 d$？

参考答法：传统 MLP 有 W_up 和 W_down 2 个矩阵（参数量 $8 d^2$）；SwiGLU 多了一个 W_gate 共 3 个矩阵，为了保持总参数量依然等于 $8 d^2$（$3 \times d \times d_{\text{ff}} = 8 d^2$），所以 $d_{\text{ff}} = \frac{8}{3} d$。
