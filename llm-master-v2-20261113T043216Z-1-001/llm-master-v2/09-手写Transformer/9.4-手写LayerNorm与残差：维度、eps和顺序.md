### 9.4 手写 LayerNorm 与 RMSNorm：维度、eps 和顺序 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：手写归一化算子时，面试白板最容易写错两个致命细节：① 把 + eps 写到了 sqrt(...) 根号外面（np.sqrt(var) + eps 在 var=0 时求导直接除零爆炸！）；② 搞混归一化维度 axis=-1 与 axis=0！

本节解法：手写 LayerNorm 与现代大模型标配 RMSNorm：严格把 eps 放在 sqrt(... + self.eps) 根号内部，沿特征最后一维 axis=-1 独立归一化，并对比 RMSNorm 省去均值中心化带来的计算加速。

大白话例子：LayerNorm 像先算全班同学（单行特征维）的平均分，再减去平均分、除以标准差，重新拉到均值为 0、方差为 1；RMSNorm 发现“减均值这一步对大模型根本没多大用”，干脆直接拿均方根（RMS）缩放一下就完事，既省了一遍求均值的显存扫描，效果还一样稳！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 任意特征张量 x: (..., d_model)。 |
| ② 做什么 | LayerNorm: 沿 axis=-1 减均值除以 sqrt(var + eps) 再仿射 gamma * x + beta；RMSNorm: 沿 axis=-1 除以 sqrt(mean(x^2) + eps) 再乘 gamma。 |
| ③ 输出什么 | 与输入同形状的尺度归一化张量。 |
| ④ 关键参数 | eps（防除零稳定项，必须放根号内；常见 1e-5 或 1e-6）、gamma（全 1 初始化）、beta（全 0 初始化）。 |
| ⑤ 工程 Trade-off | RMSNorm 去掉了均值减法与 beta 偏置，减少了 1 次全局归约（Reduction）与参数存储，推理/训练快约 10%~15%。 |

#### 3. 💻 渐进式代码实操（Step 4：LayerNorm & RMSNorm 算子）

演进说明：第 9 章积木 4 号，实现带全零防除零断言的归一化层。

```python
"""9.4 Step 4: 手写 LayerNorm 与 RMSNorm (严格把 eps 加在根号内防除零)."""

from __future__ import annotations

import numpy as np


class LayerNorm:
    def __init__(self, d_model: int, eps: float = 1e-5) -> None:
        self.gamma = np.ones((d_model,), dtype=np.float64)
        self.beta = np.zeros((d_model,), dtype=np.float64)
        self.eps = eps

    def forward(self, x: np.ndarray) -> np.ndarray:
        mean = np.mean(x, axis=-1, keepdims=True)
        var = np.var(x, axis=-1, keepdims=True)
        normed = (x - mean) / np.sqrt(var + self.eps)
        return self.gamma * normed + self.beta


class RMSNorm:
    """LLaMA/Qwen 标配：省去均值中心化与 beta 偏置，仅用均方根缩放."""

    def __init__(self, d_model: int, eps: float = 1e-6) -> None:
        self.gamma = np.ones((d_model,), dtype=np.float64)
        self.eps = eps

    def forward(self, x: np.ndarray) -> np.ndarray:
        rms = np.sqrt(np.mean(x * x, axis=-1, keepdims=True) + self.eps)
        return self.gamma * (x / rms)


if __name__ == "__main__":
    zeros = np.zeros((2, 4, 16))
    assert np.isfinite(LayerNorm(16).forward(zeros)).all()
    assert np.isfinite(RMSNorm(16).forward(zeros)).all()
    x = np.random.default_rng(3).normal(5.0, 2.0, size=(2, 4, 16))
    assert np.allclose(np.mean(LayerNorm(16).forward(x), axis=-1), 0.0, atol=1e-6)
    print("Ch9 Step 4 self-test passed!")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：全零输入绝不出现 NaN/Inf；归一化必须沿 axis=-1（特征维）且保留 keepdims=True 以便广播。

讲清关键行：np.sqrt(var + self.eps) 与 np.sqrt(np.mean(x*x) + self.eps) 把 eps 放在根号内部，确保前向分母非零且反向求导 $\frac{1}{2\sqrt{0+\epsilon}}$ 也绝对安全！

主动点出工程细节：在 BF16/FP16 混精度训练下，算 mean(x^2) 时平方项极易溢出或下溢，工业级实现（如 LLaMA）必须先 .float() 转成 FP32 算完 RMSNorm 再转回 BF16！

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：BF16 下手写 RMSNorm 偶发数值精度丢失或梯度 NaN

定位方法：直接在 BF16 低精度下做 x * x 求和。

修复方案：强制在 FP32 下执行平方求和与开方，最后再 cast 回原精度。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么 RMSNorm 的 eps 必须加在根号里面，而不是加在根号外面？

参考答法：加在根号外虽然前向分母不会为 0，但反向传播时对 $\sqrt{x}$ 求导会出现 $\frac{1}{2\sqrt{x}}$，当方差 $x=0$ 时梯度依然会除零爆炸成 NaN；加在根号内前向与反向同时免疫除零！
