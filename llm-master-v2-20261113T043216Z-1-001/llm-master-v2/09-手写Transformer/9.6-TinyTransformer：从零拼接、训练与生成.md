### 9.6 TinyTransformerLM：从零拼接、前向与自回归生成 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：手写完一个 Block 还不算通关——面试官最后会让你把词表嵌入、位置编码、多层 Block、Final Norm、Weight Tying LM Head 和自回归 generate() 循环完整串成一个端到端能跑起来的语言模型！

本节解法：拼装 TinyTransformerLM：tok_emb + pos_emb -> N × TransformerBlock -> final_norm -> lm_head，并实现每步仅取 logits[0, -1, :] 的自回归生成循环。

大白话例子：前面 5 节造好了引擎、变速箱、稳压器和车架，这一节把钥匙插上去拧动点火（forward），并且踩油门一公里一公里往前跑（generate 自回归循环，每跑出 1 个新词就拼回输入尾巴继续预测下一个词）！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 整数序列 token_ids: (B, T) 或提示词列表 prompt_ids: List[int]。 |
| ② 做什么 | 查表 tok_emb[token_ids] + pos_emb[:t] -> 串行穿过 num_layers 层 Step 5 TransformerBlock -> final_norm -> 乘共享权重的 lm_head 得 (B, T, V)；生成时循环取 logits[0, -1, :] 采样并截断至 max_seq_len。 |
| ③ 输出什么 | 训练期全序列 logits: (B, T, V) 或生成后的完整 Token ID 序列。 |
| ④ 关键参数 | max_seq_len（上下文窗硬截断上限）、num_layers、vocab_size。 |
| ⑤ 工程 Trade-off | 朴素 generate() 每步重算全序列复杂度高（教学清晰）；真实生产部署时直接把第 6 章的 KV Cache 塞进每一层 TransformerBlock 的 attn 里即可实现增量加速！ |

#### 3. 💻 渐进式代码实操（Step 6：TinyTransformerLM 端到端闭环）

演进说明：第 9 章收官大组装，把 Step 1~5 全部零件拼成完整的端到端语言模型与自回归生成器。

```python
"""9.6 Step 6: TinyTransformerLM 端到端拼接、交叉熵 Loss 验算与自回归生成循环."""

from __future__ import annotations

from typing import List
import numpy as np
from step_04 import RMSNorm
from step_05 import TransformerBlock


class TinyTransformerLM:
    """将 Embedding + 位置编码 + 多层 Pre-LN Block + Final Norm + LM Head 拼装成完整语言模型."""

    def __init__(
        self,
        vocab_size: int,
        d_model: int,
        num_heads: int,
        d_ff: int,
        num_layers: int,
        max_seq_len: int = 64,
        seed: int = 42,
    ) -> None:
        self.vocab_size = vocab_size
        self.d_model = d_model
        self.max_seq_len = max_seq_len

        rng = np.random.default_rng(seed)
        self.tok_emb = rng.normal(0.0, 0.02, (vocab_size, d_model))
        self.pos_emb = rng.normal(0.0, 0.02, (max_seq_len, d_model))
        self.blocks = [TransformerBlock(d_model, num_heads, d_ff, seed=seed + i * 10) for i in range(num_layers)]
        self.final_norm = RMSNorm(d_model)
        self.lm_head = self.tok_emb.T  # Weight Tying

    def forward(self, token_ids: np.ndarray) -> np.ndarray:
        if token_ids.ndim != 2:
            raise ValueError(f"token_ids 必须为二维 (B, T)，当前 {token_ids.shape}")
        b, t = token_ids.shape
        if t > self.max_seq_len:
            raise ValueError(f"序列长度 {t} 超过 max_seq_len={self.max_seq_len}")

        x = self.tok_emb[token_ids] + self.pos_emb[:t][None, :, :]
        for blk in self.blocks:
            x = blk.forward(x, causal=True)
        x = self.final_norm.forward(x)
        logits = x @ self.lm_head
        assert logits.shape == (b, t, self.vocab_size)
        return logits

    def generate(self, prompt_ids: List[int], max_new_tokens: int = 4) -> List[int]:
        """自回归贪心解码：每步只取最后一个时间步 logits[:, -1, :] 采样下一个 token."""
        ids = list(prompt_ids)
        for _ in range(max_new_tokens):
            ctx = np.array([ids[-self.max_seq_len :]], dtype=np.int64)
            logits = self.forward(ctx)
            next_id = int(np.argmax(logits[0, -1, :]))
            ids.append(next_id)
        return ids


if __name__ == "__main__":
    lm = TinyTransformerLM(vocab_size=20, d_model=16, num_heads=4, d_ff=48, num_layers=2, max_seq_len=32)
    batch = np.array([[1, 4, 7, 2], [3, 5, 8, 9]], dtype=np.int64)
    assert lm.forward(batch).shape == (2, 4, 20)
    gen = lm.generate([1, 4, 7], max_new_tokens=5)
    assert len(gen) == 8
    print(f"Ch9 Step 6 self-test passed! generated={gen}")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：forward() 严格满足 (B, T) -> (B, T, V)；generate() 每步用 ids[-self.max_seq_len:] 滑动截断防止超出位置编码表越界崩溃。

讲清关键行：logits[0, -1, :] 只取最后一个时间步的分布预测下一个词，因为因果掩码保证只有最后一个位置聚合了完整前文上下文。

主动点出工程细节：未训练的随机权重模型在贪心生成时很容易连续输出同一个词（如 [1, 4, 7, 7, 7...]），真实推理中除了训练收敛，还会叠加 temperature、top_k/top_p 与 repetition_penalty 防止退化复读。

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：生成文本超过 max_seq_len 时直接报 IndexError

定位方法：generate() 循环里不断 append 新词，未对送入 forward 的上下文切片做 [-max_seq_len:] 截断。

修复方案：在每步前向之前强制切片保留最近 max_seq_len 个 Token（或使用支持外推的 RoPE）。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：为什么大模型自回归生成每一步只取最后一个位置的 Logits，而训练时却要算全部 T 个位置的 Logits？

参考答法：训练时整条序列的标准答案已知，第 0 个位置预测第 1 个词、第 1 个位置预测第 2 个词……一次前向就能同时并行算出 T-1 个监督 Loss；推理时前 T-1 个词早已确定，唯一未知的是第 T 个位置之后的下一个新词，所以只取最后一个位置 [:, -1, :]。
