### 8.8 残差、LayerNorm / RMSNorm 与 FFN 的分工 【🔥 必会】

#### 1. 🎯 本节目标与大白话例子

上一步痛点：有了 Attention 之后，模型已经能让词与词之间互相交流了，为什么还需要铺设残差连接（Residual）、LayerNorm/RMSNorm，以及占了全模型 2/3 参数量的 FFN（前馈网络）？

本节解法：理清四大组件的分工协作：① Attention 管跨词信息混合（Token Mixing）；② FFN 管逐词非线性加工与事实记忆存储（Channel Mixing / Key-Value Memory）；③ LayerNorm / RMSNorm 稳住特征尺度防梯度爆炸；④ Residual + 1/sqrt(2*L) 缩放铺就深层梯度高速公路。

大白话例子：开学术研讨会时，Attention 是“大家互相传纸条交流各自查到的线索”；传完纸条后，每个人必须坐回工位自己独立消化思考、结合脑子里的百科全书（FFN）得出结论；而 RMSNorm 就像麦克风自动音量均衡器，防止某个人嗓门太大把全场震聋！

#### 2. 🧠 核心原理与五维拆解

| 维度 | 核心内容（闭卷背诵标准） |
| --- | --- |
| ① 输入什么 | 残差流 x: (B, d_model)、网络层数 num_layers。 |
| ② 做什么 | 对比残差分支输出投影未缩放 vs 乘以 1 / sqrt(2 * num_layers)（NANOGPT_SCALE_INIT）后深层方差的增长幅度。 |
| ③ 输出什么 | 深层网络末端的激活标准差 std。 |
| ④ 关键参数 | 1 / sqrt(2 * L)（因为每层有 Attention 和 FFN 2 个残差分支，累积方差为 $2L$ 倍）。 |
| ⑤ 工程 Trade-off | RMSNorm 省去均值计算与 beta 偏置，比传统 LayerNorm 快约 10%~15% 且效果无损；SwiGLU 门控 FFN 用 3 个矩阵替代 2 个矩阵（中间维度通常缩为 $8/3 \cdot d$ 保持总参数量持平），表达力显著强于 ReLU。 |

#### 3. 💻 渐进式代码实操（Step 8：深层残差方差缩放稳定性验证）

演进说明：用代码验证 GPT-2 / nanoGPT 中著名的残差输出层 1/sqrt(2*n_layer) 初始化缩放技巧。

```python
"""8.8 Step 8: 残差分支方差缩放 (NANOGPT_SCALE_INIT: 1/sqrt(2*n_layer)) 稳定性验证."""

from __future__ import annotations

import math
import numpy as np


def simulate_residual_growth(num_layers: int = 24, d_model: int = 64, use_scale_init: bool = True) -> float:
    rng = np.random.default_rng(0)
    x = rng.normal(0.0, 1.0, size=(32, d_model))
    std = (0.02 / math.sqrt(2 * num_layers)) if use_scale_init else 0.02
    for _ in range(num_layers * 2):
        w = rng.normal(0.0, std * math.sqrt(d_model), size=(d_model, d_model))
        x = x + (x @ w) * 0.1
    return round(float(np.std(x)), 4)


if __name__ == "__main__":
    std_scaled = simulate_residual_growth(24, 64, use_scale_init=True)
    std_unscaled = simulate_residual_growth(24, 64, use_scale_init=False)
    assert std_scaled < std_unscaled
    print(f"Ch8 Step 8 self-test passed! scaled_std={std_scaled}, unscaled_std={std_unscaled}")
```

#### 4. 🗣️ 面试官视角：这段代码怎么讲

先声明不变量：随着层数 $L$ 加深，残差流每经过 2 个分支（Attn + FFN）方差就会累加一次，必须用 $1/\sqrt{2L}$ 缩放输出投影层（c_proj / w_down）的初始化标准差，使深层方差保持 $O(1)$。

讲清关键行：2 * num_layers 精确对应每个 Block 里的两个残差相加点。

主动点出工程细节：为什么不用 BatchNorm 而用 LayerNorm/RMSNorm？因为文本序列是变长且有 Padding 的，BatchNorm 跨样本统计均值方差不仅受 Batch Size 影响（小 Batch 不稳），还受 PAD 污染且推理与训练行为不一致；LN/RMSNorm 只在单条样本单个 Token 的特征维 C 上归一化，完全独立！

#### 5. 🔧 生产排障指南（实现 -> 排障）

故障 1：深层模型（如 32 层）训练初期梯度震荡、前几个 Step 震幅极大

现象：Loss 剧烈抖动甚至发散。

定位方法：检查是否误用了 Post-LN（归一化在残差加法外面）或忘记给残差输出投影层加 $1/\sqrt{2L}$ 缩放。

修复方案：全面采用 Pre-LN + RMSNorm + 残差分支输出层缩放初始化。

#### 6. ❓ 高频面试追问与参考答法 + 📝 节末费曼自检

Q1：Pre-LN 和 Post-LN 区别是什么？为什么现代大模型都选 Pre-LN？

参考答法：Post-LN 把 Norm 放在残差相加之后，深层梯度回传时每次都要穿过 Norm 的缩放，越往底层梯度越小（需要严格 Warmup）；Pre-LN 把 Norm 放在子层输入前，保留了一条从输出直达输入的无阻挡恒等残差高速公路，训练极其稳定。
